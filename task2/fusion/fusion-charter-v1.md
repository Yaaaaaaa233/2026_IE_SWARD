# R3 白盒黑盒融合实验（无数据部分）v1

状态：**实验机械与对照协议完成；裁决待数据阶段的同一把 MOE 打分**
责任范围：本模块实现 D18–D20 的实验机械（融合公式、α 网格、分歧清单、话术格式），不产生任何真实对比结论；"融不融合"的裁决权在实验数据 + 组长终审，不在本模块。

## 1. 实验问题（D18）

本项目任务二的最大分歧：任务一模型概率进不进公开总分。

- **正方（融合，娄澜执笔）**：Q1（概率转换分）携带规则分之外的连续风险信息，能在档位粒度之外细化排序；融合权重 α 不参与规则学习，两套分数在验证协议上独立可检；解释性不因融合受损——扣分台账（α·Q0 部分）与维度话术（D20）覆盖司机视角，评委视角由三元散点与分歧清单支撑；0922 会议共识即白盒+黑盒按比例融合。
- **反方（纯规则，② 验证基线稿立场）**：Q1 与规则分共享同一特征底座与同一标签来源，验证标签上的一致性提升可能是同源信息的重复计分（循环论证风险在"判优"环节而非"融合"环节本身）；Q1 的校准误差直接污染公开分；司机追问"模型给我的那部分分是怎么扣的"时，任何话术都弱于规则条款。
- **裁决规则**：两组假设预先登记（上文即登记稿），数据阶段在同一 T2-R4 合同、同一 label_v2、同一折分上打分——首要门槛五分位单调，次级 AUC/AP/Top20% Lift，人因复核 5 人×10 案例（均分≥4、单项≥3）；D18 建议连同正反论证与原始报告提交组长终审。

## 2. 记号约定（D19 执行期口径，含路线图歧义澄清）

路线图 D18 写作 "α=0 纯规则 vs α>0 融合（S=α·Q0+(1−α)·Q1）"，按该公式 α=0 应为纯 Q1，与"纯规则"表述矛盾。本模块采用显式记号 **`alpha_q0` = Q0 规则分权重**，网格为 {1.0, 0.7, 0.5, 0.3, 0.0}：

| alpha_q0 | 含义 | 评价行是否携带任务一概率 |
| --- | --- | --- |
| 1.0 | 纯规则臂（②立场） | 否（`uses_task1_probability=false`） |
| 0.7 / 0.5 / 0.3 | 融合臂（D19 既定三档） | 是（并声明 OOF） |
| 0.0 | 纯模型参照臂（Q1 单独） | 是 |

该歧义已按"执行期决策点由负责人给建议并留痕"处理，D19 最终形态（全局 α 还是分群 α）由数据阶段折内选择后定。

## 3. 红线（继承路线图 §5 第 6 条）

1. 任务一概率**只出现在 Q1 与一致性参照列**，不参与任何臂的判优——选择函数只读 T2-R4 报告的五分位门与 ROC AUC；
2. 融合臂的 α·Q0 部分必须保持台账精确复算（复算容差沿用评价合同）；α 变更即升 `score_version`；
3. 纯模型臂（alpha_q0=0）无论数字多好都只是参照，不得直接成为公开分（可解释性不满足评审要求）；
4. 平手裁决偏向更大 `alpha_q0`（规则权重更高 = 解释更直接，与 T2-R4 选型规则第 4 条一致）。

## 4. 模块构成

- `fusion.py`：
  - `fuse_scores`：S = alpha_q0·Q0 + (1−alpha_q0)·Q1，车辆集合一致性与值域 [0,100] 强制；
  - `run_alpha_grid`：逐臂构造评价行（概率列按上表规则挂接与声明）并跑同一 `evaluate_scores`；机械选择器=首要门通过者中 ROC AUC 最高、平手取大 alpha_q0；
  - `rank_disagreements`：Q0/Q1/融合分三元风险排名（低分=排名 1）与最大名次差 Top-K，供人工复核与三元散点数据；
  - `dimension_talking_point`：D20 司机话术（"您的××风险高于 N% 的同行司机"），只呈现维度表现，不暴露模型内部。
- 合成测试：`tests/test_task2_fusion.py`。
