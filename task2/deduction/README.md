# R1 扣分规则引擎（无数据部分）

本目录实现 T2-R1 中不依赖任何真实数据的封闭工作包：管道骨架、参数接口与三份输出契约。数值全部由数据阶段在训练折内重学。

- [R1 章程（D7–D11 落笔与不变量）](deduction-charter-v1.md)
- [候选参数配置](deduction_policy_v1.json)（占位值，折内重学后升版）
- `contract_loader.py`：只读加载 T2-R0 分类契约（归属/角色/分母/风险链）。
- `engine.py`：事件段 → 暴露归一 → 折内分档 → EB 平滑 → PAVA 单调 → 规则压缩 → 组内边际递减。
- `writers.py`：T2-R4 评分行（含台账复算）、T2-R2 适配器载荷（含合同校验）。
- 合成测试：`tests/test_task2_deduction.py`。

边界：结果门编码（11803/11804）不参与普通扣分；证据质量角色（41006/41021）预算为零；改变分类语义必须先升版 R0 契约，本模块只读消费。
