## 一、结论先行

目前 D0 已经具备完整的训练、交叉验证、评分、解释和导出能力。现有 500 辆车特征表中，分类总纲要求的 20 个可计分行为率字段全部可用，能够被压缩为 5 个公开语义组。全仓 86 项测试通过，500 车结构化接口冒烟通过，最终分数可以由扣分台账精确复算。

现在还不能报告 D0 的真实 Spearman、AUC、PR-AUC、Lift 或正式扣分权重。原因是仓库虽然把 `sprint-g8v5-seedmean` 写为任务一当前候选最优版本，但实际逐车 OOF `model_score.csv` 没有进入 Git 历史，本机也未找到。公开复现脚本仍对应较早的三成员版本，不能据此伪造最终教师概率。

因此，当前结论是：**方法和工程链路已经可运行，真实效果尚待唯一外部输入；没有用合成概率冒充比赛结果。**

## 二、这套方法要解决什么

任务一能够给出每辆车的事故风险概率，但直接使用 `100 × (1 − p)` 只能告诉司机“风险高”，不能回答“为什么高、应该改什么”。D0 的目标是把任务一风险排序压缩成少量、稳定、单调的行为扣分规则：

- 任务一认为风险越高的车辆，D0 总扣分应总体越大；
- 某项危险行为增加时，该行为的扣分只能不变或增加；
- 相近报警先融合，避免一次风险过程被重复计罚；
- 每个分数都能回溯到行为档位、语义组和扣分点数。

D0 的定位是“任务一模型的可解释蒸馏版本”。它与现有路线的关系如下：

| 名称 | 含义 | 作用 |
| --- | --- | --- |
| B0 | 不学习权重的透明弱基线 | 效果下界与工程检查 |
| Q0 | 使用未来真实标签学习的 R1 规则分 | 主要白盒候选 |
| Q1 | 任务一概率直接转换分 | 模型效果参照 |
| D0 | 使用任务一 OOF 概率学习的规则分 | 本次新增的可解释蒸馏候选 |

## 三、技术路线

### 1. 输入只保留可干预行为

D0 只读 T2-R0 分类合同，选择角色为 `behavior` 或 `context_warning` 的事件。当前得到 20 个暴露校正发生率，归入疲劳、分心、操控稳定、安全空间、速度与道路规则五个语义组。

事故、未遂属于结果，不作为普通行为重复扣分；摄像头遮挡、角度异常主要表示证据质量，也不进入行为权重学习。

### 2. 为每项行为学习单调档位

对行为率按训练折分位点划分 3 至 4 档，计算每一档任务一事故概率的平均值，再通过 PAVA 单调回归消除小样本抖动。

得到的行为严重度记为：

`z_j = Normalize(PAVA(E[p_task1 | 行为 j 的发生率档位]))`

它被限制在 0 至 1。行为发生率升高时，`z_j` 不会下降，因此规则方向稳定且容易解释。

### 3. 融合相近行为并降维

同一语义组内部采用边际递减：

`g_k = (组内最大严重度 + λ × 其余严重度均值) / (1 + λ)`

当前候选 `λ=0.25`。最大风险行为承担主要扣分，其余相关行为只提供补充证据。这样把 20 个行为特征压缩为 5 个组信号，同时保留行为级扣分分摊。

该设计适合“同一风险链触发多个报警”的数据结构。例如车道偏移和长时间压线同时出现时，二者共同增强操控风险，但不会按照两个独立事故过程全额相加。

### 4. 学习非负扣分预算

学习目标为：

`teacher_penalty = 100 × p_task1`

然后使用非负岭回归学习基础扣分和五个语义组预算：

`D = clip(b + Σ w_k × g_k, 0, 100)，其中 w_k ≥ 0`

`SafetyScore = 100 − D`

非负约束保证危险行为增加时，安全分不会反向升高；岭惩罚用于降低五个相关组之间的权重波动。

### 5. 输出可复算解释

每辆车输出：

- D0 安全分；
- 基础风险扣分；
- 五个语义组扣分；
- 20 类行为的分摊点数；
- 前三条主要扣分原因；
- 证据是否充分；
- 规则版本与任务一教师版本；
- 独立台账复算分。

## 六、验证纪律

D0 使用 Q1 作为学习目标，因此“D0 与 Q1 很像”只能证明蒸馏保真，不能证明它对未来事故真正有效。正式报告必须分两层：

1. **教师一致性层**：Spearman、Kendall、Top20% 重合率、教师概率五分位、扣分 MAE。
2. **真实效果层**：未来事故/未遂的 AUC、PR-AUC、Top20% Lift、五分位实际出险率和子群稳定性。

所有 D0 学习操作还要执行第二层交叉拟合。即使任务一概率本身已经是 OOF，也不能在全体车辆上学完 D0 后再用同一批车辆报告拟合效果。

## 七、需要特别关注的风险

### 1. 任务一主要优化排序，不一定优化概率刻度

任务一官方评价重心是 AUC。即使车辆风险排序很好，`0.7` 与 `0.4` 的数值差也未必代表真实风险差。如果直接拟合原始概率，扣分幅度可能受校准质量影响。

正式实验建议同时比较：

- **D0-P**：拟合原始 OOF 概率，保留概率幅度信息；
- **D0-R**：拟合 OOF 风险百分位，重点保留排序，对概率失准更稳健。

D0-P 是当前已经实现的主路线；D0-R 作为效果挑战者，应在读取真实结果前固定转换和判优规则。

### 2. 教师自身使用过相同事件信息

任务一模型本身大量使用事件特征，因此 D0 学到的是教师模型对这些行为的风险归因，不等于行为导致事故的因果效应。报告中应使用“风险关联扣分”或“模型蒸馏扣分”，不能写成因果结论。

### 3. 相关行为可能分配不稳定

同组融合和岭惩罚可以降低不稳定性，但仍需报告五折权重方向、档位边界和主要原因的一致程度。如果总效果稳定而单项权重剧烈变化，应进一步合并行为，不能展示一张看似精确但不可复现的扣分表。

## 八、拿到真实概率后的执行顺序

1. 核验 `model_score.csv` 只有一个模型版本，确认是 OOF，车辆无缺失无重复，概率在 `[0,1]`。
2. 核对模型版本是否确为 `sprint-g8v5-seedmean`，记录文件指纹；若团队正式采纳版本已变化，则使用新版本并升 D0 规则版本。
3. 按冻结五折运行 D0-P 的第二层交叉拟合，生成教师一致性结果。
4. 使用冻结未来标签运行 R4 真实效果评价，比较 B0、Q0、D0、Q1。
5. 在相同输入上预登记并运行 D0-R；若两者差异不显著，选择档位更稳定、解释更直接者。
6. 全量拟合最终规则，只用于交付扣分表，不把全量拟合结果冒充折外效果。
7. 选取高风险命中、低风险正常、模型与规则分歧、低暴露、近期改善/恶化车辆做人因复核。

## 十、当前判断

D0 值得作为独立候选继续推进。它比直接使用 Q1 更可解释，比完全依赖专家权重更有数据依据，也通过组内融合控制了重复计罚。当前最大的未知不是算法能否运行，而是它在最终任务一 OOF 概率上能够保留多少风险排序，以及这种排序在真实未来事故标签上是否仍然有效。

在正式概率文件到位以前，最合理的状态是“工程通过、效果待验证”，不能提前宣布 D0 优于 Q0 或可以成为最终公开分。
