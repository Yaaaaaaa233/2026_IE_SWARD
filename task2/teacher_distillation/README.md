# D0：基于任务一概率蒸馏的可解释扣分路线

D0 是一条独立候选路线：以任务一的车辆级折外事故概率为软学习目标，把风险排序压缩成可公开复算的行为扣分规则。它不修改 R1/Q0、R2、R3 或 R4。

命名关系：

- B0：不学习权重的透明弱基线；
- Q0：R1 使用未来真实标签学习的规则分；
- Q1：任务一概率直接转换分 `100 × (1 − p)`；
- D0：本目录实现的任务一概率蒸馏规则分。

## 原理

1. 从 T2-R0 分类总纲只读取 `behavior` 和 `context_warning`，当前形成 20 个暴露校正行为率；事故、未遂和设备质量编码不作为普通扣分项。
2. 每个行为率在训练折内分箱，以任务一 OOF 概率的箱内均值为风险信号，再用 PAVA 强制“行为率升高时风险不下降”。
3. 同一语义组先做“最大项 + 0.25 × 其余均值”的递减融合，将 20 个行为维度压缩为 5 个语义组信号，缓解相关报警重复扣分。
4. 用非负岭回归拟合 `100 × 任务一概率`，得到五个组的扣分预算。非负约束保证任一危险行为增加都不会让安全分上升。
5. 输出基础风险扣分、组扣分、行为分摊和前三条原因；台账可以独立复算总分。

## 为什么必须交叉拟合

任务一概率已经是 OOF，但 D0 仍会学习分箱和权重。评价时必须再次按车辆折分：每一折的 D0 规则只能在其他折拟合，再给该折打分。全量拟合规则只用于最终交付，不能拿来报告训练内拟合效果。

对 Q1 的 Spearman、Kendall、Top20% 重合率、概率五分位单调和扣分 MAE 只能证明“蒸馏得像不像”。它们不能独立证明 D0 对真实事故有效。最终采用仍须在新的未来窗口上比较 AUC、PR-AUC、Lift、分群稳定性与人因复核。

## 输入

- 行为特征：`gpsno`、暴露量和 `rate_<事件编码>_per_1000km`；
- 教师概率：`gpsno,prob,calib_flag,model_version`，必须是完整 OOF 概率；
- 折分：优先使用任务一固定折；未提供时 CLI 使用与概率无关的稳定哈希五折；
- 可选真实标签：只用于单独报告真实结果指标，不参与教师一致性指标。

最新版公开说明指向 `sprint-g8v5-seedmean`，但当前 Git 历史没有实际 `model_score.csv`。因此代码不会用旧概率或合成概率冒充正式结果；拿到该受控文件并核对版本、车辆集合和指纹后再运行。

## 运行

输出目录应放在被忽略的 `artifacts/` 或其他受控位置：

```powershell
python -m task2.teacher_distillation.run `
  --features artifacts/task2/vehicle_features.csv `
  --teacher-scores artifacts/task1/model_score.csv `
  --folds artifacts/task1/splits.csv `
  --teacher-model-version sprint-g8v5-seedmean `
  --output-dir artifacts/task2_teacher_distillation
```

产物包括交叉拟合分数、教师一致性指标、全量交付规则、可读扣分表和最终分数。真实概率、权重、车辆分数与指标均留在受控目录，不提交公开仓库。
