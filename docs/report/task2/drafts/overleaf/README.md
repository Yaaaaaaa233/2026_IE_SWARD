## 这次相对现有第 10 章补了什么

1. 新增“冻结评分结果”小节，明确 500 车分布、低暴露数量与内部代理指标。
2. 将 AUC、AP、教师一致性和五分位倒挂分别解释，避免把不同证据混成一个结论。
3. 将 UI 从“建议”改为已经可以演示的页面结构，并标明真实冻结字段与结构演示字段。
4. 把四类名单的进入条件、动作和退出条件放进同一张表，便于老师判断是否能形成管理闭环。
5. 增加两个演示案例模板和可读性验收标准，方便答辩前人工检查。
