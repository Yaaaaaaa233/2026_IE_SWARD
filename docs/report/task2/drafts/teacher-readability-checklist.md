# 任务二结果与UI教师可读性检查表

请评审者在不听作者口头解释的情况下完成。每题按1至5分评分，并记录最先产生误解的位置。

| 检查项 | 评审问题 | 通过标准 |
| --- | --- | --- |
| 总体方向 | 30秒内能否说出安全分越高越好，风险分位越高越危险？ | 平均不低于4 |
| 结果含义 | 能否说清AUC表示排序而不是事故概率承诺？ | 平均不低于4 |
| 证据状态 | 是否理解低暴露车辆不能直接参加优秀评选？ | 任何评审不低于3 |
| 雷达图 | 能否分清五个行为维度与证据可信度？ | 平均不低于4 |
| 趋势图 | 能否判断改善、恶化和停驶冻结的差别？ | 平均不低于4 |
| 排名 | 是否会混淆安全排名和风险排名？ | 无人混淆 |
| 行动建议 | 是否能从司机详情找到下一步动作？ | 平均不低于4 |
| 正向激励 | 是否理解优秀表扬还要求证据充分和连续稳定？ | 平均不低于4 |
| 数据身份 | 是否能识别冻结结果与结构演示值？ | 无人混淆 |
| 边界 | 是否知道内部代理结果不等于官方未来成绩？ | 无人误读 |

## 开放问题

1. 第一眼最想点击哪里？界面是否支持这个动作？
2. 哪一句话最难理解？
3. 哪张图的信息重复或不足？
4. 如果你是安全管理者，看完后会采取什么行动？
5. 如果你是司机，是否知道怎样改善以及如何申诉？
