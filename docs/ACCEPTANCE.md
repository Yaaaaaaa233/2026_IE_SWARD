# 人能读懂的验收与证据规范

这是各 agent 的通用交付格式。M0—M3 名称目前来自候选路线，只用于组织验收，不代表算法路线已经接受。真实图表遵守 [数据边界](DATA_POLICY.md)，默认保存在受控本地报告中。

## 1. 一页验收首页

每个阶段至少交付：本次问题、一句结论、关键图表、范围与样本量、异常解释、未证明事项、下一步、复现入口。使用 [验收模板](templates/acceptance.md)。

状态分别报告，禁止只给一枚绿色 PASS：

| 维度 | 回答的问题 |
| --- | --- |
| 实现／数据契约 | 功能是否按预期工作？时间、单位、输出是否合法？ |
| 实验效果 | 是否优于固定对照？差异和波动有多大？尚未运行则写未运行 |
| 验收与证据 | 报告能否追溯到同一运行？检查器能否发现预期错误？ |
| 环境与依赖 | 数据、权限、内存或运行环境是否限制结论？ |

合法结论：`pass`、`partial`、`fail`、`not_run`、`blocked`，必须注明对象和范围。团队是否进入下一阶段是单独的决策，agent 只提出建议。技术检查通过不自动证明算法有效，图表漂亮也不构成证据。

## 2. 各阶段应交付的图表

| 阶段 | 最小可视化交付 | 人类验收问题 | 需补验证／返工的典型信号 |
| --- | --- | --- | --- |
| M0 数据审计 | 分数据源的车辆×日期覆盖图；每日事件、活跃车与标签趋势；标签构成 | 数据是否完整？异常来自行为还是采集？模型实际预测什么？ | 大段缺失无解释；把无记录当安全；单位不明确 |
| M1 评估与基线 | 特征／标签时间轴；折外风险分组与后续出险比例；不同划分表现 | 模型是否只看过去？高风险组是否真的更常出险？ | 只报训练分；分组不显示样本量；时间来源不清 |
| M2 候选验证 | 相对基线提升及波动图；效果与成本图；组合增益图 | 新方法是否稳定有用？值不值得继续？是否只是重复信息？ | 折分不一致；只选最好一次；多项同时变化却作单因果解释 |
| M3 最终方案 | 去除特征组后的变化；分群表现及样本量；输出完整性检查 | 模型依赖什么？哪些车辆效果差？能否重复生成合法提交？ | 小群体无样本量；训练推理特征含义不同；遗漏车辆 |
| 任务二评分 | 单车扣分瀑布图；分数与行为随时间变化；评分档与后续风险 | 扣分能解释和追溯吗？停运／掉线是否反而加分？ | 无数据得满分；恢复规则说不清；用同窗事故扣分证明同窗相关 |

每张图必须标注数据时间、样本量、单位、代码／配置或运行编号、数据来源与一句结论。指标方向要写清：风险分越高越危险，安全分通常相反。覆盖图显示记录覆盖，不能无依据写成设备在线率。

## 3. 常见指标如何说明

- AUC：随机比较一台正类和一台负类，风险排序正确的程度；不是分类准确率。除 AUC 外展示风险分组实际结果。
- 相对提升：使用同样车辆、标签和折分，比较新旧方案；显示零提升参考线。
- 波动：多个种子只是划分敏感性，不是新的独立数据；区间跨零是证据可能不足，不自动证明无效。
- 分群指标：同时报告人数与正类数；不足时明确标记不可可靠比较，禁止用不稳定小样本作强结论。
- 模型重要性／SHAP：解释模型使用了什么，不证明因果，也不直接等于司机扣分权重。

## 4. 报告必须从真实运行生成

受控本地证据包建议包含：

```text
reports/local/<run-id>/
  report.html 或 report.md  # 人类验收入口
  result.json              # 各维度状态和真实指标
  manifest.json            # 代码、配置、数据指纹、依赖、种子、时间窗
  figures/                 # 从同一结果生成的图
  tables/                  # 绘图底表与必要的折外结果
```

这是输出合同，尚未实现通用报告生成器。记录代码提交；若工作树有改动，另存补丁指纹和说明。不能用固定数值填模板，也不能把上一次运行的图附在本次指标上。

验收脚本返回可解析结果，失败非零退出。基础设施新增检查至少用一个人为构造的坏输入验证它确实能拒绝；不能仅凭自己的 PASS 文本自证。依赖缺失写 `blocked/not_run`，不要默默跳过并报全绿。

公开仓库只记录允许公开的证据索引。数据包中的敏感指纹、表格与实际图表不因“证据要求”而被强制公开。

## 5. 问题关闭与停止条件

开始验收前确定范围、门槛、对照与预算。问题关闭保留原问题复现、针对性修复验证及相关回归。新发现说明是算法、数据、验收器还是环境问题，只影响相应结论范围。

冻结范围检查通过且限制明确后可以停止；新增实验方向另开任务，不无限扩大同一轮验收。未经实际独立复核的结果保留“实现者自测”标记。
