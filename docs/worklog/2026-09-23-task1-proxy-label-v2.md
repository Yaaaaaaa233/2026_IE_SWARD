## 做了什么

## 验证

合成测试覆盖同日两次、精确重复、单次未遂、事故、右边界、折分复现、源版本拒绝混用与禁止覆盖。真实受控产物通过 500 车键集合一致、旧负类不转新正类、五折双类、标签／折分 manifest 校验和一致的检查；受控 `acceptance.png` 展示标签迁移与逐折类别。`python3 tools/check_governance.py` 通过；`python3 -m unittest discover -s tests -v` 的 30 项通过；脚本编译、任务 JSON 解析及 `git diff --check` 通过。真实正类数、逐车表与文件指纹仅在受控目录。

## 决策与限制

正式 8/1 后标签在赛事方手里，生成器只处理可检验的历史代理窗口。现有 F1/F3 输入及旧 OOF 未自动重绑新版标签；旧画像时间可见性与 7/31 来源恢复也未处理。因此不产生任何新版模型性能或采纳结论。
