## 做了什么

1. **误差归因诊断**（[models/solution_b/analyze_errors.py](../../models/solution_b/analyze_errors.py)）：
   对 v1 全量折外预测逐台归因（H0–H6 六项假设检验）。定性结论：
   - 漏报主体是"特征上安静的普通车"——其画像与真负类几乎无差别（可分性仅略高于随机），
     属**特征信息量天花板**而非模型形式问题；换任何模型都排不出来；
   - 前百名单误报并非暴露量混杂（暴露分位≈平均），更接近事故本身随机性；
   - AUC 损失主要分布在跨群对与低风险群内对；高风险群内一致率明显偏低且群定义特征在群内饱和；
   - 特征窗内历史出险是最强新信号候选（复发率显著高于基线），但只能覆盖少部分漏报——
     已整理为 F1 特征需求文档（受控）递交特征线。
2. **模型侧三项迭代实验**（[models/solution_b/improve_b.py](../../models/solution_b/improve_b.py)，均为负结果，按预登记规则全部不采纳）：
   - 多种子成员包（RF/EBM 各三种子）：成员方差确有收窄，但经 B1 后无净增益；
   - 单调约束 LightGBM 第三成员：单调先验在当前特征集上为错误约束，单模显著弱于 RF/EBM，拖累融合；
   - 高风险群校准收缩先验 n0 网格：按 AUC 选择会挑中激进设置、严重损害概率质量——
     **教训：校准类超参应按概率质量指标（Brier）选择，而非对校准中性的 AUC**。
   - 净结论：v1 的 B1 配置在当前 F0 特征下已接近模型侧最优；**提升路径锁定特征侧（F1）**，
     与误差诊断互相印证。v1 交付文件与采纳层级维持不变。
3. **配套产出（受控本地，不入库）**：F1 特征升级需求文档（致特征线，含真实统计与验收承诺）、
   方案B可视化 demo v2（500 车逐车交互页面，内嵌 ECharts 单文件；含真实车辆数据仅限内部）、
   真实数字实验记录（improve_b_log / error_analysis_vehicles.csv）。
4. 提案补记：[model-route-proposal.md](../plans/model-route-proposal.md) §4.2 记录负结果与"模型侧到顶"判断，防止重复投入。
