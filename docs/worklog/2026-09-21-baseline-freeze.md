# EVAL-002 任务一基线冻结与采纳判据落地

## 背景

- 叶安（纪律管理）授权按推荐方案冻结基线。前置判断：MODEL-004 三项模型侧迭代均无预登记规则下的可采纳增益、结论"资源投向特征侧"；特征线 F0/F1 已交付，迭代开始前必须冻结评估参照，否则后续特征版本的增益无法归因。
- EVAL-001 v0.1 为 Proposed，其 §8 列明冻结前置项（管理名额政策、实际增益门槛、可接受退化量、ADR 记录）。

## 本次完成

1. **本机受控复跑双基线**：仓库外 venv（`.venv-baseline`，按 requirements.txt 同口径安装 numpy/pandas/scikit-learn），`python models/task1_baselines.py --feature-root <受控特征根>`；输入优先取 `model_input.csv`（F0_v1）。硬检查通过（500 行、一车一行、y 二值、fold 完整；特征入口 60 数值 + 1 类别）。
2. **配对 bootstrap + 叶安裁定单参照**：用 `metrics.paired_bootstrap_auc`（2,000 次、95%、种子 42）检验随机森林对 L2 逻辑回归的差异，区间下界 > 0 且 ≥ 0.01 → 叶安裁定只以随机森林为冻结基线（单参照，随采纳演进），L2 LR 降为起草期对照（数字留台账，不参与判优）。Recall@100 配对区间跨零，按规则不作显著宣称。数值见受控台账 §7。
3. **文档落地**：新增 ADR-0004；EVAL-001 升 v1.0（Accepted）——§6.3 冻结登记（输入指纹 sha256、单参照基线身份、配对 CI 采纳判据、升版规则）、§8 标注已冻结/仍开放项；decisions/tasks 索引更新；COLLABORATION §4 增加冻结对照指针。
