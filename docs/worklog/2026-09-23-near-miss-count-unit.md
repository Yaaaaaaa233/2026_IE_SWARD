## 做了什么

叶安在了解“按记录／独立事件／日期”歧义后要求“按照次数算吧”。据此在 [ADR-0007](../decisions/ADR-0007-near-miss-count-unit.md) 裁定：标签窗口内，`events_clean` 中每条精确去重后保留的有效 `11804` 记录计一次；同日不同记录分别计次，不按出现天数或 30 秒并段数。同步数据契约、评价基座、公共调整方案与状态页；没有改动算法线代码。

## 验证

公共文档中的待确认描述已与 ADR-0007 区分；`python3 tools/check_governance.py`、JSON 解析与 `git diff --check` 通过，`python3 -m unittest discover -s tests -v` 的 28 项通过。新版真实标签、折分与模型未运行。

## 决策与限制

官方只明确“未遂至少 2 次”；逐条记录计次是团队内部可复算约定，不声称赛事方确认。精确重复行仍只保留一次；坐标或速度异常不会导致标签事件被删除。若官方之后另定单位，再走 ADR 升版。旧协议效果结论仍冻结，预测窗精确右端及时区仍待明确。
