1. 按新版标签与折分重建 F0/F1/F3 代理输入，并保存逐车绑定、来源文件哈希、标签／折分版本和时间窗清单。所有动态车辆画像、未核实的 `energy_type`、画像偏差、群体派生和画像交互列均从代理输入排除；F3 从注册基座与原始新特征候选表重建，未沿用旧版全样本筛列结果。无标签筛列、填补和编码在嵌套训练折内拟合。
2. 在新输入和新版折分上重跑随机森林锚点。旧协议 RF/V5 OOF 未用于本轮比较。由于没有可核验的新口径 V5 OOF，本轮预登记以新版 RF 为唯一主对照；该预登记与输入指纹保存在受控目录。
3. 按五外折、三内折和固定候选完成一次 F1/F3 嵌套 OOF，执行配对 AUC 区间及辅助指标计算，并生成同 run ID 的主比较图、逐折诊断、排名关系和 Top-100 重叠材料。
4. 独立复核程序重新读取锁定输入、RF OOF 和候选 OOF，逐项复算样本／折分／预测有效性、禁止字段、输入指纹与主要指标。复核结果与运行报告一致。合成防泄漏测试覆盖训练折变换隔离、验证标签扰动和无画像分群键情形。
5. 首次候选尝试在运行期间因查明两列由未来画像派生而中止；该尝试没有导出 OOF、指标或可用模型。补齐排除列后更新预登记及输入哈希，再启动有效 run。两个 run ID 和处理记录留在受控输出中，未覆盖。
6. LightGBM 首次加载因系统缺少 OpenMP 动态库失败。模型代码未改动；依赖从 conda-forge 下载并解包到隔离目录后通过加载检查。实际运行环境与对应 macOS ARM64 环境文件一并记录。
