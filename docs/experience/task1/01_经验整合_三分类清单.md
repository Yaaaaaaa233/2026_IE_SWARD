## B. 算法选择

### B1 一定有效

| # | 做法 | 证据 |
| --- | --- | --- |
| B1-1 | **强平滑无交互 EBM 为主力**（interactions=0；bins 32~64；leaf 10~20 网格） | 叶安 F3 五折全选 EBM-A=0.845；EBM-C（bins32/leaf20）=0.847——平滑越强越高 |
| B1-2 | **严格嵌套**：外 5 冻结折 + 折内 3 折选型，预处理/填补/编码/筛列/cohort 全部折内拟合 | 叶安 0.845 骨架；我线 V5 校准材料事故反证（跨折平均 → 0.8009 掉 0.7963） |
| B1-3 | **RF 锚 + LR 锚基线**（仓库登记实现） | 双线各自 0.813——一切迭代的对照原点 |
| B1-4 | **浅 LightGBM 做对照成员**（leaves 4~8 / min_data 30~40） | 叶安候选池成分；深树在 54 正类下必过拟合 |

### B2 可能有效

| # | 方向 | 依据与不确定性 |
| --- | --- | --- |
| B2-1 | **logit 平均小融合**（EBM-A + EBM-C + RF 或浅 LGBM，2~4 成员） | 旧协议稳定 +0.01 量级（V1→V5 证据）；v2 下未试；风险：与最优单模差异小时增益有限 |
| B2-2 | EBM 平滑参数细扫（bins×leaf×学习率×外 bagging 小网格，折内选） | EBM-A→C 只动了两个参数就 +0.002；网格未扫完 |
| B2-3 | 全局校准（Platt/等张，仅概率质量） | v2 下 V5 全局臂 0.8288 > S1 0.8128；对 AUC 中性、对 Brier 有益 |
| B2-4 | 特征族折内自动加权/选择（每折重估族贡献） | 有机理；风险：54 正类下选择噪声大 |

| # | 做法 | 证据 |
| --- | --- | --- |
| B3-1 | 深度模型（MLP 等）做主模型 | 旧协议 MLP 单模 0.668 溃败；n=500/54 正类无空间 |
| B3-2 | 距离/协方差类（KNN/QDA） | KNN 0.768；QDA 协方差奇异直接出局 |

| B3-5 | 温度缩放调排序 | 旧协议 V5 实证排序不变仅动 Brier |

## C. 综合判断（给路线图的输入）

1. **成败在特征工程**：算法侧共识已收敛（强平滑 EBM + 严格嵌套 + RF 锚），剩余方差在"喂给 EBM 什么信息"。叶安 F3→0.845 的本质是把**未消费的数据面**（轨迹/同群/事件结构）变成了 ~40 列高信息密度特征。
2. **我方超越路径**按信息源正交分组：事件序列深挖、纵向面板动态、事件×轨迹联合上下文、（叶安强项+我方融合的）融合同群组、极简对照。每组独立可归因，横向对照定位主力族。
3. **0.9 的现实差距**：当前最高 0.847（事后身份）。到 0.9 需再 +0.05，为历史最大单步增益的 1.7 倍。测量噪声（54 正类配对 bootstrap 的典型半宽 ±0.03）意味着接近 0.9 的版本也难以"统计显著"地与 0.85 区分——目标按组长口径执行，结果诚实报告，累计 30 版无好结果可停。
