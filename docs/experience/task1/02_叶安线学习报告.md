## 2. 0.845 是怎么拿到的（机制拆解）

**特征侧（F3 构成）**：FEAT-006 剪枝瘦基座（lean，109 列）+ 新增四类族（≤40 列上限）：
- Tier 1 强信号精修：历史险情时间结构（近5天衰减加权、复发间隔、爆发性、历史×趋势）；同群相对化（群键=能源类型×高速占比中位二分，群内 z/百分位，**统计量折内拟合**，群内<30 车回退全体）；画像基线偏差；夜间退化度（深夜率÷日间率）；
- Tier 2 轨迹族（44GB 流式一遍扫描）：连续驾驶切段（间隔>180min 切）、速度形态（p50/90/99、CV、高速巡航>80km/h 占比）、空间结构（DBSCAN 热点、路线重复度、活动半径）、日节律（里程 CV、断档天数）；
- Tier 3 事件结构：连环（≤30min）、共现类型对、爆发密度峰、|EMS−GPS| 双速度源差异、事件时速；
- 收尾通则：|Spearman ρ|>0.95 成对去后者、近零方差剔除、同场景只留 per_1000km 版。

**算法侧（严格嵌套，`modeling.py`）**：外层冻结五折 → 每个外折的训练部分内 StratifiedKFold(3, seed42) → 四候选（EBM-A 无交互 bins=64 leaf=10；EBM-B 交互=5；LightGBM-A leaves=4/min30；LightGBM-B leaves=8/min40）按内层平均 AUC 选一 → 外折训练部分重拟合 → 预测外折。**F3 的五个外折全部选中 EBM-A**；F1 折间混杂。预处理（中位数填补、独热、相关性/方差剪枝、cohort 特征）全部折内拟合，带拟合范围指纹断言。

**EBM-C（0.8472）**：interactions=0、max_bins=32、min_samples_leaf=20——比 EBM-A 更强的平滑。事后探索，复跑字节一致。

## 3. 值得继承的优点

1. **严格嵌套是 0.845 的骨架**：一切预处理/选型折内拟合 + 拟合范围指纹，可审计。
2. **强平滑无交互 EBM 是 54 正类下的冠军 learner**（EBM-A 全折被选；EBM-C 更平滑更高）。方向明确：小正类 → 更强正则。
3. **"新信息矿脉"方法论**：三轮负结果后转向未消费数据面（轨迹/同群/画像偏差/事件结构），而不是继续重组已有特征——这是 F3 质变的来源。
4. **瘦基座 + 列预算 + 收尾通则**：直接吸收 FEAT-006 共线稀释教训（全量叠加只 +0.0094）。
5. **S0 审计文化**：画像派生依赖逐列追踪，运行中发现派生列即中止重登记。

## 4. 缺陷与局限（我的突破口）

1. **0.845 无法归因**：F3 vs F1 同时改变特征构成与选型结果；预登记五块消融只做归因不做过门判定且未见公开数字；观测量（coverage/IMU 行数）混杂未消融（FEAT-010 B0/B1 设计了但未跑）。**→ 谁贡献了 0.033 仍是黑箱。**
2. **energy_type / highway_ratio 口径松动**：这两列在他的 v2 排除清单里（静态未核验 / 聚合期至 7-31 的动态画像），但 `modeling.py:144-148` 将其作为 context 列**重新加回特征矩阵**，cohort 群键也依赖它们。代理回测成绩可能含未来信息成分。复现其成绩时必须知道这一点。
3. **事件表消费深度不足**：3.09M 行 22 类事件，只压成了语义计数 + 少量结构（连环/共现/爆发）。类型转移模式、事件间隔分布形态、昼夜节律的序列表达、事件之间的车-日纵向结构基本未挖。
4. **单模型无融合**：0.845/0.847 均为 EBM 单模；我线旧协议证据：EBM+RF logit 平均稳定 +0.01 量级。v2 下未试。
5. **IMU 基本放弃**：98GB 只进了 F0 时代少量窗口统计；方向无关模长/设备校准表的深挖在新标签（真实事故导向）下未重评。
6. **vehicle_day 纵向结构未挖**：60 天×500 车的日粒度面板（里程/时长/事件/覆盖）只被聚合，日间动态（工作节律、断档恢复、周末模式）是现成的廉价信息源。
7. **EBM-C 只调了两个平滑参数**：bins/leaf 的小网格外还有正则维度（learning_rate×n_estimators 组合、外 bagging）未扫。
