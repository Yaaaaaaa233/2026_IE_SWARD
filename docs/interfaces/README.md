# 公共契约入口

当前仅建立契约管理方式，尚未冻结数据实现、字段命名或评估配置。后续按需建立三类契约，避免多人各做一套定义。

| 契约 | 必须明确 | 冻结前允许的工作 |
| --- | --- | --- |
| 数据契约 | 车辆键、字段类型与单位、时间语义、重复／缺失、来源版本 | 原始审计与读取原型 |
| 评估契约 | 样本、特征／标签窗、标签定义、折分、指标方向、拟合边界、最终推理口径 | 基线设计与合成数据验证 |
| 评分与输出契约 | 评分方向、维度、低暴露与无数据处理、更新机制、ID 和文件列 | 可解释规则原型 |

公共语义变化需新增或修订 [决策](../decisions/README.md)，记录版本、受影响消费者、失效实验和迁移方式。任务分支可以提出草案，不得以本地临时实现覆盖共享合同。

版本化配置进 Git；机器路径和敏感数据指纹留本地。契约的合成测试可在 CI 执行，真实数据测试在授权本机执行。
