# 可引用证据索引

公开仓库的证据目录不默认接收比赛数据、真实统计或图表。按 [数据边界](../DATA_POLICY.md) 区分公开元信息和受控完整报告。

| 证据 | 范围 | 状态 |
| --- | --- | --- |
| [治理初始化](governance-bootstrap.md) | 文档结构、检查器、自测与数据禁入规则；无真实数据计算 | 实现者自测，团队复核待完成 |

当前没有已登记的模型或司机评分验收成绩。此前本地初查不等于正式 M0 通过。

新证据说明：任务、代码版本、配置、运行方式、检查范围、实际复核状态、未支持的结论。受控证据包参照 [验收规范](../ACCEPTANCE.md)，不能因跨设备协作而把敏感数据上传公开 GitHub。
