# 任务一双基线运行证据

## 证据范围

- 任务：任务一事故风险预测 C1 基线。
- 模型：L2 正则化逻辑回归、随机森林。
- 输入：受控本地统一模型接口，车辆级一车一行。
- 口径：20 天特征观察窗、40 天标签窗、冻结车辆五折；外层训练部分内进行分层三折调参。
- 输出：合并 OOF 指标、各折指标、选定参数与逐车 OOF 概率。

## 实现与复现

- 实现入口：`models/task1_baselines.py`。
- 执行方案：`docs/plans/task1-baseline-execution.md`。
- 指标定义：`docs/plans/评价指标与基线对照方案（MOE与MOP）.md`。
- 默认随机种子：42。
- 本轮已完成代码自测、治理检查与全量基线运行。

## 公开边界

真实样本统计、指标数值、逐车标签和 OOF 预测保存在受控本地报告中。根据 `docs/DATA_POLICY.md`，公开证据只登记运行范围、实现版本、检查类型与限制，不公开数据派生数值。

## 结论边界

本证据支持“两个基线已按冻结折协议完成内部回测”，不支持“已取得独立测试集成绩”或“已证明跨月份泛化”。模型替换判断仍需后续配对不确定性分析和正式保留数据。
