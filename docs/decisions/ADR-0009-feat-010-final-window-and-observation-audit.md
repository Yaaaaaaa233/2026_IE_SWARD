## 背景与决策

FEAT-009 已完成新版标签下的开发期代理技术运行，但数据、标签和评估登记仍待实际责任人复核；其 20 天特征窗的代理成绩不能当作最终 61 天历史输入的成绩。受控诊断提示排序与 IMU 观测量有关联，但尚不能判断这是采集量影响还是有效行驶暴露。

接受叶安线 FEAT-010 v1.0 的两项工作：A0/A1 复核公共证据、字段来源与最终 61 天无标签输入的窗口／单位／缺失语义；B0/B1 在原 20＋40 代理协议中，对预先固定的六个直接观测量列做一次移除对照。每步的具体操作、机器验收、合成坏例、人工可视化验收和放行门以接受版本为准。王健祺线新版 V5 不作为本任务开工依赖；本决策不修改其代码或安排。

**本次仅授权方案入库**。未完成的 EVAL-001／EVAL-003／FEAT-009 人工复核、各步前置合成样张与执行认领仍按方案门槛办理；方案入库不表示新基线已正式冻结、61 天模型可验证、B 步实验已运行或 FEAT-010 已验收。

## 依赖、预算和未决事项

- A0 使用已登记的新代理标签、折分及 FEAT-009 受控证据作只读输入；A1 可先做不计分的 61 天工程检查。B 的真实效果判定以 EVAL-001／EVAL-003 协议和 FEAT-009 来源复核真实完成为前置。
- 资源估计：A0 约半日，A1 半日至一日，B0/B1 各约半日；只允许一个预登记的有效完整 OOF。超预算或发现源数据／协议问题时保留记录并停止，不临时扩大搜索。
- 未决：最终 61 天训练如何得到与推理同义且标签严格在特征窗之后的训练样本；官方预测窗右端与时区的进一步澄清；EVAL-001／EVAL-003 责任人的实际复核结果。这些不能由方案接受推定解决。

## 备选、影响与迁移

备选“直接用 61 天特征对现有代理标签算 AUC”会让代理标签期信息进入特征，故不采用。备选“继续广泛调参或增加多个消融组”会扩大已反复使用样本上的选择偏差，故本轮只设一个诊断候选。FEAT-009 主跑和事后 EBM 探索保持原版本与受控目录；FEAT-010 用新 run ID、新清单留档，失败和负结果也记录。若需改变公共标签、折分、评估规则或采纳基线，另走相应 ADR，不由本决策自动升版。
