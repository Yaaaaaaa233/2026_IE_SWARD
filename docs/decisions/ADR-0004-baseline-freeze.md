# ADR-0004 任务一基线冻结与采纳判据（EVAL-001 升 v1.0）

- 状态：Accepted
- 决策人：叶安（仓库建立与纪律管理）
- 日期：2026-09-21
- 任务：[EVAL-002](../tasks/EVAL-002.json)
- 执行：ZCode agent（按叶安（纪律管理）授权落地）

## 背景

- 样本量 500、正类约四分之一，五折合并 OOF AUC 的噪声底约 ±0.02（单折 ±0.03）；L2 逻辑回归 61 个系数已接近该样本量可稳定供养的参数预算。
- MODEL-004 的三项模型侧迭代（多种子包 / 单调 LightGBM / 收缩 n0 网格）按预登记规则均未产生可采纳增益，结论为"资源投向特征侧"。在特征侧开始迭代前，若不先冻结评估参照，后续各特征版本的增益无法干净归因。
- [EVAL-001 v0.1](../plans/评价指标与基线对照方案（MOE与MOP）.md) 为 Proposed 状态，其 §8 列明接受前置项；本 ADR 逐项补齐可当前冻结的部分。

## 决策

1. **基线身份唯一化（单参照）**：任务一冻结基线＝随机森林——300 棵、`max_features=sqrt`，`max_depth ∈ {4,6,None}`、`min_samples_leaf ∈ {5,10}` 折内选；实现 `models/task1_baselines.py`，默认种子 42。起草期曾以 L2 逻辑回归为对照锚点，冻结运行显示随机森林对其配对区间下界 ≥ 0.01（数值见受控台账）；叶安裁定只保留效果最好的一条作基线，避免双参照在团队执行中造成混乱。L2 逻辑回归数字保留于台账作起草期对照，不参与判优；其系数解释用途不受影响。
2. **评估协议冻结**：输入为特征线交付的 `model_input.csv`（feature_version F0_v1）、折分 `split_v0.1_strat5`、指标实现 `models/solution_b/metrics.py`（11 项单测）、管理名额 `K = ceil(0.2N)`、同分按 `sample_id` 字典序。冻结基线的登记数字与逐车 OOF 预测保存于受控本地目录（`outputs/task1_baselines/` 与本地台账），不入公开仓库（DATA_POLICY）。
3. **采纳判据改为配对置信区间口径（单参照）**：任何新版本与冻结基线（随机森林）在相同车辆、标签、折分上做车辆级配对 bootstrap（预登记 2,000 次、95% 百分位区间、种子 42）。区间下界 > 0 且点估计 ΔAUC > 0 方可判"超过基线"；声称"有实际意义增益"另需区间下界 ≥ 0.01；辅助指标容差：Recall@100 退化 ≤ 0.02、Brier 退化 ≤ 0.005；多种子（42/7/2026）方向一致仅作旁证，不单独构成采纳依据。基线随采纳演进：某版本按本判据被采纳后即成为下一轮基线（登记于受控台账）。废弃以裸点估计差值 0.005 判优的旧口径（低于噪声底，会把噪声收编为改进）。
4. **升版规则**：基线与协议仅在以下情形重置——官方就 30/40 天标签口径作出正式澄清、标签认定协议变更、折分表变更。重置须经新 ADR + EVAL-001 版本号递增，并把已采纳版本在新协议下重跑后重新登记；已有实验不能无记录地换口径。
5. **证据边界**：本冻结为开发期内部回测参照，不构成独立测试集成绩或跨月份时间外推证据（沿用 v0.1 §5.2/§5.3 的限制表述）。

## 备选与取舍

- 等官方 30/40 天口径澄清后再冻结：更稳妥，但特征线 F0/F1 已交付、迭代在即，无参照的风险大于口径微调风险；澄清后按第 4 条升版重跑即可，不采用。
- 双参照结构（L2 LR 归因锚点 + RF 采纳门槛）：判据最细，但两套参照易在团队执行中产生混乱，叶安裁定简化为单参照，不采用。
- 单锚点 L2 LR：系数可解释、合 MODEL-002 线性锚点路线；但冻结运行显示随机森林对其配对区间显著占优，以弱者为唯一基线会把不如现有最强简单模型的版本误判为改进，不采用。
- 沿用 0.005 裸差值门槛：低于噪声底，统计上不可分辨，不采用。
