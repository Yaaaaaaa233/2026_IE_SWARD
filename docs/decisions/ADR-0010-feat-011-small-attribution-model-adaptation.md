# ADR-0010：叶安线既有特征的小规模建模适配方案入库

- 状态：Accepted（**仅方案**；FEAT-011 S0–S3 均未运行）
- 决策人：叶安
- 日期：2026-09-25
- 任务：[FEAT-011](../tasks/FEAT-011.json)
- 接受版本：[FEAT-011 方案 v1.0](../plans/feat-011-small-attribution-model-adaptation-plan.md)
- 决策依据：叶安在阅读方案及其可能结论的解释后指示“入库”。

## 背景与决策

FEAT-009 已得到新版协议下的 F3 时间可见输入，但“增加特征”和“调整学习器”尚无独立归因；FEAT-010 的观测量对照也仍受前置复核门约束。接受 FEAT-011 v1.0 作为叶安线下一轮**小规模、有归因的工作方案**：固定同一 F3 输入与五折，比较全量／深夜精简两种特征视角和 EBM-A／EBM-C 两种既有模型配方；仅将全量 F3 EBM-A 与精简 F3 EBM-C 的等权 logit 融合作为唯一新增主候选，以 `E−A` 为主比较。

本决策只确认方案范围和步骤门槛，不确认特征效果、模型增益、跨线胜负或正式采纳。S0–S3 均为 `not_run`；真实候选 OOF 须等 EVAL-001、EVAL-003 与 FEAT-009 所需实际责任人复核，并在 S0 输入审计、S1 合成坏例和预登记通过后才可运行。FEAT-010 B0/B1 可以并行，不自动改变本轮输入。王健祺线代码和公共评价基座不在本决策写入范围。

## 依赖、预算与未决口径

- 依赖：FEAT-009 v2 Y1 F3 受控表与主跑、EVAL-001／EVAL-003 新协议的真实复核，以及 [ADR-0006](ADR-0006-official-qa-foundation.md)、[ADR-0007](ADR-0007-near-miss-count-unit.md) 规定的公共口径。未完成的人工复核不能由本次方案接受代替。
- 预算：A–D 四个固定训练臂各最多一套有效五折 OOF，E 仅确定性融合；合成冒烟和单折成本试验先行。主跑预计超过 6 小时或资源不足时，须在真实 OOF 前修订方案与预登记，不临场追分。
- 未决：FEAT-009 F3 OOF 在同输入同配置下能否复现；精简深夜列是否释放有效信息；E−A 的配对区间和辅助指标是否过门；王健祺线是否提供同协议、同车的合格 OOF 供 S3 诊断。未获得证据前均不作结论。

## 备选、影响与迁移

备选“直接扩大调参和特征搜索”会在已反复使用的代理样本上扩大选择偏差；本轮固定 2×2 因子矩阵和一个主候选。备选“按王健祺线公布成绩直接选融合权重”缺少同车同折、来源可核对的证据，因此只允许后续受控的诊断性模拟，不进入本轮主判定。

FEAT-009、FEAT-010 与王健祺线既有产物保留各自版本身份。FEAT-011 只在新 run ID 和受控目录留存输入指纹、逐车 OOF、真实图表与指标；公开仓库仅保留方案、代码和无真实数值的交接。若本轮停止或失败，停止消费 FEAT-011 新产物即可回退；改变公共标签、折分、评估或正式基线仍须另作决策。
