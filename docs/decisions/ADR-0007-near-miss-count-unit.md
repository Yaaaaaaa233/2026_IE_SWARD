# ADR-0007：任务一未遂“次数”按有效事件记录逐条计数

- 状态：Accepted（团队内部计数约定；不冒充官方对计数单位的进一步解释）
- 决策人：叶安
- 日期：2026-09-23
- 任务：[GOV-008](../tasks/GOV-008.json)
- 依据：叶安在 0923 官方答疑后的明确指示“按照次数算吧”；官方阈值见 [ADR-0006](ADR-0006-official-qa-foundation.md)

## 背景

官方明确任务一正类阈值为 `11803` 事故至少 1 次，或 `11804` 未遂至少 2 次，但未说明同日多条 `11804` 记录应按记录、并段后的独立事件还是发生日期计数。为使项目数据与评估口径一致，团队需要先选定可复算的内部单位。

## 决策

对每台车、每个已声明的标签窗口，以清洗层 `events_clean` 中**保留的有效 `11804` 事件记录数**作为未遂次数；一条记录计一次。同一天的两条不同有效记录计两次。不按不同日期计数，不作 30 秒并段，也不因坐标或速度字段异常而删除该条事件。精确重复行依既有清洗规则只保留一条；车辆键、事件编码或时间无效的行不得静默计入。

对应二分类规则为：`y = 1` 当且仅当该窗口内 `count(11803) >= 1` 或 `count(11804) >= 2`；否则在日志完整假设下为 `0`。计数范围与时间边界必须随 `label_version` 记录。此规则不能回写成旧“任一未遂即正类”。

## 影响与验收

- 数据线以此生成下一版标签，评估线在相同标签和新版折分上比较；旧标签、旧折分和旧效果结论继续保持历史身份。
- 合成边界例：同车零事故、同日两条不同 `11804` 记录应为正类；仅一条有效 `11804` 记录应为负类；两条完全相同的源行精确去重后只算一次。
- 这只确定公共标签计数单位，不指定叶安线、王健祺线的模型、特征、实验次序或重跑策略。新版标签文件及真实数据验收尚未完成。
- 若赛事方随后明确不同的“次数”定义，需新 ADR 升版并登记受影响实验。预测窗精确右端与时区仍待确认。
