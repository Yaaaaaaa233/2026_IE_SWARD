## 1. 任务一句话与评审口径

基于任务一特征底座与行为证据，交付一套**可解释、可运营、可动态更新**的司机安全评分体系。官方评审四维：**风险区分 35% / 可解释性 25% / 可运营性 20% / 完整性 20%**。
0923 答疑会确认：任务二**无固定 CSV 模板，为自由形式分析报告**（建议附评分表）；线上初评只看任务一 AUC，任务二须同步提交（结果+文档）不计分，初赛/决赛综合评审；gpsno 可作司机唯一评价单元。

## 2. 输入资产与设计总纲

三份调研（task2/ 目录，不同 AI 独立完成、互证设计）为选型输入，**择优融合而非三选一**：
①《指标分类 v1》：8 大类 32 小类目录（24/24 编码核对、证据状态三分、10 条交叉裁决）——**目录层与边界纪律来源**；
②《特征分类与验证基线实施稿》+工作簿：22 类双层分类、五条风险链、**R1 扣分引擎（已实现，AUC 0.775、五分位单调）**、验证纪律全案、人因复核方案——**实现骨架与验证纪律来源**；
③《行为大类划分与扣分规则方案调研》（娄澜）：六大类+模糊项 M1–M8 裁决、四方案对比（推荐混合分层制）、修正系数设计——**框架与运营机制来源**。

```text
分类总纲 R0（周航正）
   ├──────────┬──────────┐
   R1 扣分规则(娄澜)   R4 MOE与基线(周航正)     ← 并行
   ├──────────┴──────────┘
   R2 可运营微调(周航正) R3 融合实验(娄澜)      ← 并行
   └──────────┬──────────┘
              R5 交付（全员）
```

核心权衡（0922 会议共识，③重申）：解释性与区分度存在 trade-off——白盒规则保证"每一分扣得有依据"，模型概率校正总方向；**是否融合留待 R3 实验裁决**（②主张不进公开分防循环论证，③与会议共识主张融合——对照实验定胜负）。

## 3. 分阶段实施清单（含各环节决策点 D1–D25）

### T2-R0 · 分类规则设计（周航正，先行，09-24～09-25）

**目的**：三版分类融合为《分类总纲 v1》——评分体系的"宪法"。

负责人与依赖：周航正；输入=①②③三份调研；无前置。

具体操作：
- [ ] **D1 大类结构**：建议三层——公开层 5 人因维度（②）← 语义层 6 组（②③一致）← 目录层 32 小类（①）；备选：①8 类平铺 / ③6 类平铺；
- [ ] **D2 事故/未遂处理**：建议一票降档（③，兼容"历史险情进总分"口径）；备选：①H 类扣分 / ②仅作标签；
- [ ] **D3 模糊项 M1–M8 逐项裁决**（③已列备选与理由；组长勾选）；其中 D4 盲区机制建议"仅装配群内计罚（M7 实证 8.4% vs 39.1%）+ 变道分母（②）"；
- [ ] **D5 IMU 条件项（①D01–04/H03–04、③第七类跨源）**：建议本轮占位不启用，待 IMU 三硬伤修复后按 ADR-0004 过门；**D6 连续驾驶疲劳暴露 A04** 同批；
- [ ] ①的 10 条交叉行为裁决表收录为去重规则手册；②的五条风险链合并规则（60/120/600 秒）并入；
- [ ] 逐编码映射表 + 证据状态标注（事件/条件/预留）。

机器验收：24/24 编码唯一映射校验；每个小类有证据来源与边界一句话。
可视化验收：三层结构一页图 + M1–M8 裁决表（组长勾选留痕）。
放行条件：组长确认总纲；D1–D6 全部落笔。

### T2-R1 · 扣分规则设计（娄澜，09-25～09-27，与 R4 并行）

**目的**：在总纲上落 Q0 白盒扣分——数值处处有依据。

负责人与依赖：娄澜；依赖 R0 总纲、**叶安标签口径 ADR（硬依赖，官方正类=事故≥1 或 未遂≥2）**。

具体操作：
- [ ] **D7 主线引擎**：建议以②的 R1 引擎为骨架（事件段→暴露归一→折内分档→EB 平滑→PAVA 单调→规则压缩→组内边际递减）；备选：从零实现③方案四全量；
- [ ] **D8 数值依据**：建议未来标签学习法（②R1，已验证）；EBM 切档蒸馏作挑战者实验（EXP-002）；专家先验做底线（R0）；任务一系数/IV 归一因循环论证风险仅作参照；
- [ ] **D9 暴露分母**：首版总里程代理（②现状），轨迹接入后按行为分母切换（驾驶小时/变道次数/场景里程）——切换即重学全部档位；
- [ ] **D10 分档与组内聚合**：4 档+最大单项+0.25×其余均值（②）起步，人因反馈过繁再降 3 档；
- [ ] **D11 标签口径**：官方新口径（54 正类）——待叶安 ADR 落地后重学②的全部档位与规则表；
- [ ] 扣分实例全链路追溯字段落地（①的接口设计：谁/何时/小类/证据/规则版本/金额）。

机器验收：追溯率 100%；独立复算逐分一致；单调性断言（减少危险行为分数不降）。
可视化验收：单车扣分瀑布图 + R1 规则表（档位×风险×扣分）。
放行条件：Q0 折外数字（五分位单调+AUC）入受控报告；D7–D11 落笔。

### T2-R4 · MOE 与基线（及评价标准）（周航正，09-25～09-26，与 R1 并行）

**目的**：给任务二立"尺子"——评价标准与双基线。**MOE 不冻结**（组长批示），随迭代演进，登记于本文。

负责人与依赖：周航正；可与 R1 并行（判据设计先于数字产生）。

具体操作：
- [ ] **D21 首要判据组合**：建议以②验证纪律为核——五分位单调为首 + AUC/PR-AUC/Top20% Lift 次要 + 可复算 + 公平性（能源/车型/低暴露不反转）；吸收③的 Kendall 进次要；
- [ ] **D22 人因复核**：②方案（5 人×10 固定案例，5 项评分平均≥4、单项≥3）——定人定时；
- [ ] **D23 基线集合**：双基线——R0 透明规则分 + Q1 概率转换分（S=100×(1−p_V5)，任务一登记最优版本）；
- [ ] 主标签=官方新口径（依赖叶安 ADR）；任务一概率只做一致性参照（Spearman/Top-K 重合），不参与判优——循环论证红线（③）。

机器验收：判据可执行脚本化（负向测试：坏输入被拒）。
可视化验收：判据一页表 + 基线对照模板。
放行条件：组长确认判据组合；D21–D23 落笔。

### T2-R2 · 可运营与动态微调（周航正，09-27～09-29，R1/R4 完成后）

**目的**：把静态扣分账本改造成运营可用的动态考核。

负责人与依赖：周航正；依赖 R1（规则引擎就位）。

具体操作（决策点 D12–D17，②的修正表+③的系数设计为底稿）：
- [ ] **D12 时段系数**：建议从数据学各时段系数（G7 先验方向：7–9 点与 23–5 点最高约 1.5–2 倍；**官方夜间=21:00–次日 6:00**，注意与我方旧特征 22–5 时口径差异）；固定值（夜间×1.5/清晨×1.3）做兜底；
- [ ] **D13 EWMA 半衰期**：5/7/14 天折内敏感性后定（执行期决策点）；
- [ ] **D14 持续性/定期性加重**：跨天重复×系数（0922 会议明确"50 天前与 5 天前不一样"）；
- [ ] **D15 恢复机制**：有暴露连续安全回分 + 无暴露冻结上一有效分（②红线：不开车不得自动满分）；
- [ ] **D16 低暴露与停驶**：向总体先验收缩并标记 + 最小暴露门槛双轨；
- [ ] **D17 核查豁免流程**：可疑项挂起 N 天未核转扣；N 与流程写进说明文档运营假设节。

机器验收：EWMA 确定性复现；无数据车满分断言（禁止）；微调后 MOE 不劣化。
可视化验收：单车 60 天分数演化曲线+事件叠加；分档分布图。
放行条件：D12–D17 落笔；微调版 Q0 数字入受控报告。

### T2-R3 · 白盒黑盒融合实验（娄澜，09-27～09-29，与 R2 并行）

**目的**：用对照实验裁决"任务一概率进不进总分"——本项目任务二最大分歧。

负责人与依赖：娄澜；依赖 R1（Q0 就位）与 R4（判据就位）。

具体操作：
- [ ] **D18 融不融合（对照实验设计）**：α=0 纯规则（②立场：防循环论证、保解释性）vs α>0 融合（③+0922 共识：S=α·Q0+(1−α)·Q1）——同 MOE 打分（五分位单调+AUC/PR-AUC/Lift+5×10 人因复核），数据裁决；正反方论证（娄澜执正方，②立场由验证基线稿作者或 AI 补反方）写入实验假设；
- [ ] **D19 若融合，α 形态**：全局 α∈{0.3,0.5,0.7}（折内选）先行，时间允许分群差异化（执行期决策点）；
- [ ] **D20 黑盒解释话术**：维度表现呈现（"您的跟车风险高于 80% 同行"），不暴露模型内部。

机器验收：融合分覆盖 500 车、值域合法、可复现。
可视化验收：Q0/Q1/融合分三元排名散点 + 不一致车辆清单（人工复核弹药）。
放行条件：实验报告+D18 裁决建议提交组长终审。

## 5. 红线（继承+任务二特有）

1. 继承任务一全部红线（防泄漏、数据边界、结果诚实）；
2. 无数据不得满分；停驶冻结不归零；
3. 扣分必须可追溯（小类/事件/时间/条款/规则版本）；核查未过不扣分但挂起；
4. 单调性断言：减少危险行为分数不降；
5. 不承诺因果（评分是管理排序工具）；行业对标只借结构不引数据（③合规红线）；
6. 训练纪律：一切参数（档位/平滑/系数/α）只在训练折学习；任务一概率不做判优依据（循环论证红线）。
