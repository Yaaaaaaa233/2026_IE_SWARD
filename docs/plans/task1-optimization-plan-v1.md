# 任务一优化方案 v1（双人竞优模式）

状态：Accepted（v1.0，2026-09-22，[ADR-0005](../decisions/ADR-0005-task1-dual-track-and-task2-split.md)）
配套验收规程：[task1-optimization-acceptance-v1](task1-optimization-acceptance-v1.md)
维护人：叶安。本文不含真实数据派生统计（数值见受控台账 `docs/plans/roadmap_overall_numbers.md`，git 忽略）。

## 1. 目标与边界

- 在 2026-10-15 截止前，以**特征工程为主线**提升任务一冻结基线：每个特征族按 ADR-0004 配对判据验证，过门才采纳，基线棘轮前进。
- **官方口径锚点（2026-09-22 核实，赛题 PDF）**：任务一评分＝纯 AUC 排序（§5.1，概率值不参与打分，仅要求 [0,1] 提交格式）——本地以 AUC 为主的判据与官方对齐，概率校准类工作对成绩无直接贡献；时界按任务详情"未来 40 天"收口（概述 30 天与详情 40 天的矛盾以此为准），主回测 40 天维持。
- 同步为任务二提供可解释特征底座：特征命名即证据、语义单调先验、事件级产物（车/时刻/类型/强度/置信度），任务二扣分维度可直接映射。
- 模型侧维持受控迭代：冻结基线（随机森林）之上的模型变化同样走配对判据；可解释性不构成放松判据的理由。
- 边界：本文只覆盖任务一执行线与任务二接口约定；任务二内部方案由任务二线自定。

## 2. 共同底座与裁决器（双线共用，不得单方变更）

| 基线 | 随机森林冻结基线（ADR-0004，随采纳演进） | 仅按采纳判据棘轮前进 |

裁决流程：双方提交候选 → 统一评估器在受控 OOF 预测上复算配对区间 → 过门者采纳（双过门取区间下界更高者）→ 新版本登记指纹并成为共同基线 → 双方在新基线继续。

**叶安线（特征主线，write_scope：`feature_engineering/` + 特征侧文档 + `outputs/`）**：执行本方案 §4 阶段 0 与迭代期（阶段 1）的特征侧迭代；可解释性四原则贯穿（特征即证据／单调先验／事件级产物／评分映射链留痕）。

**王健祺线（自主方向，write_scope：`models/` + 模型侧文档 + `outputs/`）**：方向自定，建议候选（不受限）：单调约束 GBDT 与冻结基线对照、分群集成（方案 B）、概率校准与 Top-K 排序优化、特征×模型组合实验。纪律＝同底座同裁决器＋任务登记＋负结果也登记。

两线每轮工作各自按 ADR-0003 登记 task JSON；公共文件零触碰；发现需改公共件时提请纪律管理（叶安）走 ADR。

## 4. 阶段计划

### 阶段 0：就绪与探针（09-22 ~ 09-24）——登记 FEAT-003

1. **F1 真实数据运行＋配对评估**：以已入库 F1 管线（FEAT-002 代码、合成测试已通过）在真实契约数据上生成 F1_v1 `model_input`；与冻结基线同折配对比较；特征族级消融定位（历史险情族／碰撞预警族／多尺度窗口／暴露归一各贡献多少）。
   - 预期偏差登记：特征窗内事故类事件极少，IMU 阈值回放校准将按设计输出"金标准不足、暂缓校准"，属预期不阻塞。
   - 验收门：见验收规程 §5 矩阵 FEAT-003 行；FEAT-002 的 review 以本任务证据收口。
2. **两个前置探针**（纯增量，不动共享文件，产物落 `outputs/probe/`）：
   - 陀螺质量审计：抽样车辆统计陀螺量级分布、尖峰率、卡死率、与二阶段死区窗检测（C3）的重合度；顺带核查 IMU 行数两套口径差异（ADR-0005 善后项）。
   - 设备系→车辆系对齐可行性：抽样车辆以重力方向＋行驶主轴估计对齐矩阵，检验对齐后"前向加速度均值显著大于横向、重力轴集中"的物理合理性；覆盖方向异常车组（规模见受控台账）。

### 阶段 1：双线迭代期（09-25 起，开放结束——由人工推进门控制）

本阶段不是通向终评的固定流水段，而是**双线各自的迭代循环**：每人自行多轮"修改特征工程＋模型 → 与基线配对对比效果 → 记录版本"，形成各自最好的算法。进入阶段 3 的唯一途径是人工推进门（见下），无日期自动触发，agent 不得自行推进。

**迭代循环单元**（每轮）：

1. 登记：新任务或既有任务新轮次（FEAT-/MODEL- 前缀＋轮次号）；
2. 改动：特征、模型或两者组合，方向自定；
3. 评估：统一评估器出 OOF 预测；
4. 对比：对**当时基线**做车辆级配对 bootstrap（ADR-0004 判据，双线同规）；
5. 版本登记三件套：git 提交（代码+文档）＋受控 `outputs/<task-id>/round-<N>/`（OOF 预测、配对区间、manifest）＋受控台账迭代登记行（版本号→代码提交→输入指纹→对当时基线的结果→过门与否）；
6. 决策：过门则基线棘轮前进（双方在新基线上继续迭代）；未过门按负结果登记，同样进版本史（负结果也是版本，方便回溯哪条路不通）。

**版本比对**：迭代登记表支持自比（本人各版本随基线演进的效果曲线）与互比（双线同基线版本横向对照）；任何历史版本可由统一评估器在受控 OOF 预测上复算复验。

**叶安线首批迭代内容**（示例路线，非全局固定；细节沿用下述技术方案）：

- 第 1 轮（F2 主管线）——stage 0 质量层（做在特征管线内，不动清洗五版）：陀螺/加速度尖峰、卡死、饱和检测＋死区窗复核＋去噪平滑；对齐矩阵：每车设备系→车辆系变换（重力＋行驶主轴），分能源类型校验，救回方向异常车的前向/横向特征；六场景提取（对齐赛方《IMU 数据风险分析参考资料》）：急加速／急刹车（前向加速度阈值）／急转弯（角速度＋横向加速度方向一致双约束）／猛打方向（横向波动＋角速度同步，与急转弯按持续性与突发性区分）／疑似碰撞（前向／侧向／复合三分）／疑似侧翻（z 轴＋角速度），阈值按能源类型给初值，**仅以官方碰撞预警事件做相对校准信号，绝不用标签窗调参**；事件级产物表：schema 一次成型（车／时刻／类型／强度／置信度／持续），供任务二扣分明细直接消费，字段一旦被任务二消费即冻结（ADR-0005 §4）；每车聚合特征：六场景计数与频率（复用 F1 暴露归一双轨）；顺手修复：IMU 频率特征分母为 0 时输出缺失而非 0、覆盖缺口指示列复核。
- 第 2 轮（事件语义第二批，成本低）：时段×类型交叉（如凌晨疲劳）／事件发生时车速（交付表 `speed` 列）／事件爆发性与连环性（单日密度峰值、事件间隔）／周环比趋势扩展。
- 板凳（视余量）：轨迹衍生——超速时长占比、连续驾驶时长分布、凌晨长途里程；需重扫轨迹大表，仅在迭代期余量充足时启动。

**王健祺线**：迭代方向自定（见 §3），同底座同裁决器，每轮同样走版本登记三件套。

**人工推进门（进入阶段 3 的唯一途径）**：由叶安、王健祺**共同宣告**"迭代到此为止"（群内确认，EVAL-003 登记时备注宣告人与日期）。**最迟兜底**：提交截止倒推，最迟 10-11 宣告（10-12 起阶段 3、10-13~15 提交打包），防止迭代耗尽提交缓冲；届时若双方未宣告，由纪律管理（叶安）发起收口确认。

### 阶段 3：双线终评与模型定型（人工宣告后启动，最迟 10-12）——登记 EVAL-003

1. 双线候选终评：统一评估器配对裁决，产出交付模型与最终数字（受控台账登记）。
2. 单调 GBDT 等模型侧候选与冻结基线对照（王健祺线主责，判据同上）。
3. 任务二接口联调：任务二线以只读方式消费最终特征底座与事件表，登记指纹。

### 阶段 4：提交打包（10-13 ~ 10-15）——登记 TASK-006

预测 CSV（`forecast_result.csv`：gpsno,accident,risk_prob）＋评分 CSV＋说明文档＋可复现代码包（含清洗脚本入库或已知限制登记——ADR-0005 善后项在此了结）；预留缓冲。

## 5. 防泄漏与诚实红线（全程有效）

- 特征只用特征窗 `[as_of−20d, as_of)` 数据；特征期历史事故可入特征；标签窗事件只做标签。
- IMU 阈值校准不用标签窗；官方碰撞预警仅作相对校准信号（非完整标注，命中率不得宣称检测准确率）。
- 不以裸点估计差值宣称改进；多种子（42/7/2026）同向仅旁证。
- 负结果照登记（沿用 MODEL-004 惯例）；两线互不引用未过门结果作前提。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| IMU 大表重扫算力开销大 | 沿用分块多进程流式设计；探针先行验证再全量；六场景与对齐在同一次扫描内完成 |
| 方向异常车对齐不确定 | 探针阶段单独评估该组；对齐失败者保留方向无关特征并置方向特征缺失 |
| 二阶段 C3 死区检测全量化未收口 | F2 stage 0 自带死区复核逻辑兜底，不依赖上游收口 |
| 双线评估口径漂移 | 裁决一律以冻结评估器对受控 OOF 预测的复算为准（ADR-0005 §2） |
| 迭代期无限延长、挤占提交缓冲 | 人工推进门（双线共同宣告）＋最迟兜底日（10-11 宣告、10-12 起阶段 3）；每轮轻量验收控制单轮成本 |
| 时间盒溢出 | 轨迹衍生等板凳项明确可砍；阶段 4 预留一天缓冲 |
