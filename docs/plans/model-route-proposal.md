## 1. 提案动机与依据

- 样本为 500 台车的车辆级二分类（正类为标签窗内出现事故/未遂），小样本决定了"特征质量 > 模型复杂度"的基本判断；模型选型以"正则化线性 + 可解释非线性"为主力、提升树为特征升级后的复测轨。
- 数据侧已确认的结构性问题（暴露混杂、设备分层、长尾、共线、阈值型非线性）分别对模型的归一接口、分层能力、变换鲁棒性、正则强度与非线性容量提出了明确要求——组合方案库按"问题→能力"映射组织。
- 0918 会议决策：AUC 之外引入 Recall（预警名单覆盖）双指标；方案 A（单一全局模型）与方案 B（分群集成）并行验证择优。
- 数据线已落地契约五表、五版数据与冻结折分；本提案全部实验在冻结输入与折分上执行，历史实验数字只保留相对排序参考。

## 2. 方案 A：八种组合方案库（C1–C8）

| 编号 | 名称 | 构成 | 定位与启用条件 |
| --- | --- | --- | --- |
| C1 | 极简基线 | L2 逻辑回归单模型 + 冻结 F0 特征 | 全队共同比较起点；任何管道变更后先跑它确认无回归 |
| C2 | 双主力 | ElasticNet + EBM，折外秩平均 | 特征正式版后的默认主线候选 |
| C3 | 稳健三角 | ElasticNet + EBM + 随机森林，折外秩平均 | **默认推荐**：三种机制互补、方差互抵、维护成本低 |
| C4 | 可解释优先 | C2 + WoE 评分卡 | 任务二联动最强：评分卡直供扣分档位解释 |
| C5 | 非线性押注 | EBM + 单调约束 LightGBM + CatBoost | 仅当特征复测显示树系翻身时启用 |
| C6 | 分群集成 | 见方案 B | 与方案 A 并行验证 |
| C7 | 分层 Stacking | 基学习器组 + 逻辑回归元学习器（嵌套验证） | 仅当方案 B 出现明确子群差异后作为路由自动化升级 |
| C8 | 概率结构 | cloglog 离散时间风险模型 + ElasticNet 融合 | 需车辆日时变特征；任务二前瞻分需求时启用 |

组合选择指引：调试期 C1 → 主线 C3（解释叙事需要时 C4）→ 特征复测树系翻身则 C5 → 方案 B 验证期 C6 与 C3 同折对照 → 子群差异明确再上 C7 → 前瞻口径需求引入 C8。所有切换以配对 bootstrap 区间为准。

## 3. 方案 B：分群集成设计要点

- **群组键用显式规则**（可复算、可解释、防泄漏）：G-radar（有盲区硬件标记，读数据线标注口径）/ G-low / G-high（无标记 × 里程中位二分）/ G-global（兜底）。最小群 80 台，跌破并入全局；聚类标签仅作设计参考，使用时必须折内拟合。
- **子模型**：每群 ElasticNet 为主、EBM 为对照；全局兜底模型与方案 A 共享。超参沿用冻结配置，群内不重新大范围调参。
- **群内校准为强制步骤**：各群基准出险率差异大，未校准的群间概率直接混合排序是首要错误来源；每群在折外预测上拟合 sigmoid。
- **路由两档递进**：R1 硬路由（规则分派）先行；R2 软路由（元学习器加权或按折外误差倒数加权——对应会议讨论的两种办法）仅在 R1 验证出现明确子群差异后启用，且元层严格嵌套。
- **回退链**：校准失败→该群用全局模型；群规模跌破→并群；路由不稳→退 R1；整体不敌方案 A→提交用方案 A，群组画像反哺任务二同群展示。

### 4.1 E-B v2 修订：硬路由 → 校准先行 + 收缩残差（2026-09-21，随 MODEL-003 v1 落地）

在 F0 特征上的开发期实测发现：高风险簇（约百台规模、正类集中）**单独建模不可行**——簇定义所依据的传感器特征在簇内已饱和，独立子模型排序差于随机；数据不足群规模过小无法建模。据此将方案 B 的执行形态修订为三层递进（详见 [models/solution_b/](../../models/solution_b/README.md) 与受控验证报告）：

1. **B0 全局骨架**：RF + EBM 双成员嵌套折外，logit 均值融合；
2. **B1 分群校准**（替代 E-B1 硬路由）：全局模型出概率后按群校准——低风险群独立校准、高风险群向全局收缩（权重 n/(n+80)）、数据不足群纯全局并显式标记；跨群排序由校准修正，不切训练数据；
3. **B2 收缩残差**：群内残差模型在 logit 层按 λ 收缩混合，λ 网格只在训练折内选择，λ=0 时恒等回退 B1（v1 实测全部折自动选 0，按预登记规则回退，属收缩保护的预期行为）。

E-B2/E-B3/E-B4 维持不变；E-B1 原硬路由仅保留为 F1 特征升级后的复测对照项。原 §3 中 G-radar 显式群组键在当前契约表中无设备字段，待数据线补字段后启用。此修订待 R0/R4 评审确认后同步至[总体执行路线图](roadmap_overall.md)。

### 4.2 模型侧迭代负结果与投向判断（2026-09-21，随 MODEL-004 记录）

在 F0 特征上完成全量误差归因与三项模型侧迭代实验（多种子成员包、单调约束 LightGBM 第三成员、群校准收缩先验 n0 网格），按预登记判优规则**全部不采纳**，v1 的 B1 配置维持。两条可复用的定性结论（实验记录见任务 MODEL-004 与受控报告）：

1. **漏报主体是特征上的"安静车"**（与安全车可分性近随机）：当前特征信息量已用尽，模型形式侧无剩余空间；提升路径锁定特征侧——已向特征线递交 F1 需求（历史出险族、暴露归一双轨、多尺度窗口、IMU 阈值回放校准）。
2. **校准类超参应按概率质量指标选择**：按 AUC 选 n0 会挑中损害 Brier 的激进设置（校准变换对 AUC 近中性）。

据此建议：R4 前段不再投入模型形式迭代，资源转向 F1 消融复测与方案 A/B 终局对照（E-B4）。
