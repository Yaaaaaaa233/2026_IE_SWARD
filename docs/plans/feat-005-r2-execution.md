## 3. 技术方案

### 3.1 波动特征族（主攻）

一遍扫描统计（对齐通过车在对齐坐标系、全部有数据车用设备系合模长——方向无关天然可比）：

- 前向/横向/垂直加速度与陀螺 z'（对齐车）及设备系合模长（全部车）的窗内 **std / IQR(p75−p25) / 变异系数**；
- **相对波动**：样本超过本车 p90、p95 的占比；
- **时段分波动**：早高峰（7–9 点）与深夜（23–5 点）各自的加速度 std；
- **趋势波动**：前 10 天 std / 后 10 天 std 比值。

### 3.2 时段×事件交互

基于 F2 事件表时刻：早高峰事件计数、深夜事件计数（六场景合并与分场景两版）及 per_1000km 版；低暴露沿既有置缺失规则。

### 3.3 设备健康分族

- **陀螺饱和计数**（|ω| > 300 dps 行数与占比）＋**全量核查饱和矛盾**：综述 5 辆样例出现 431.9 dps 定值而 F2 探针 40 辆窗内 max 仅约 145 dps——本轮全量统计一次定案（矛盾结论入受控台账）；
- **逐字重复率**：相邻样本六轴完全相同的占比（综述样例级发现的方向，全量量化）；
- **段首毛刺率**：以间隔 >60s 切段后，段首行超全体 p99 的段占比；
- 既有 coverage_* 族保留入模（不重建）。

### 3.4 方向无关六场景（扩覆盖）

以三轴合模长与 |ω|（不需对齐矩阵）对急加速/急刹合并档（"纵向异常"，合模长无法分前后向）、急转/猛打合并档（|ω| 分位）、疑似碰撞/侧翻物理档触发分位数阈值，覆盖 125 辆对齐失败车；对齐通过车另有方向版（r1 已有），两版并存以 `f2r2_dirless_*` 前缀区分。

### 3.5 实现与算力

- 扩展 `accident_pipeline_f2/`（新增波动/质量/方向无关统计模块与 cli 阶段），复用 r1 对齐产物；合成测试覆盖波动统计正确性、方向无关触发、时段过滤与标签窗排除；
- 一遍扫描（约 5 分钟量级，参照 r1 实测）；统一时间转换为 ns 后再取秒（r1 已修复的缺陷类，写成模块级约定）；
- 分片内按车辆分组、组内按时间排序后才计算逐字重复率与段首毛刺（综述提示块内乱序，实测已确认需排序）。

## 4. 评估与消融（流程与 r1 同构）

- 候选＝冻结 RF 规格 @ r2 model_input，对基线 RF@F0_v1 车辆级配对 bootstrap（PREREG）＋多种子旁证（42/7/2026）；
- 消融矩阵：r2 全量／仅波动族／仅时段交互／仅健康分／仅方向无关六场景／波动＋时段交互；
- **预登记预期**（判据不放松）：波动族正贡献（本土＋文献双支撑）；时段交互中等；健康分贡献集中于原覆盖缺口段；整体受"司机因素约 37% 上限"约束，未过门即按负结果登记。

## 5. 验收（对照规程矩阵迭代轮次行）

L1 全项＋版本三件套＋合成测试；L2 轻量（波动抽样目检：抽 3 辆人工对原始窗段核 std；健康分抽样核对饱和计数；时段交互抽 2 辆对事件时刻）；L3 图组 B（新特征分布与单调性）＋D（健康分与官方事件交叉，如适用）；采纳时补全 L2/L3 与图组 E。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 波动族与多窗口族共线（新近度即波动的一种） | 消融含"仅波动"与 r1 多窗口复验，共线由 RF 自身处理并登记特征重要性 |
| 时段窗口样本稀疏（早高峰行数少） | 时段 std 设最低样本门槛，不足置缺失 |
| 饱和矛盾核查改变陀螺特征口径 | 核查先行（扫描第一输出），如饱和确凿则 r2 陀螺波动用去饱和样本重算并登记 |
| 逐字重复率与死区判据混淆 | 本特征是行级精确重复（与时窗方差判据无关），定义预登记 |
