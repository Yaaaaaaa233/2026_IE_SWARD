## 1. 目标与 r4 裁定背景

三轮已有事实：r1／r2 全族点估计同向为正、三种子一致但未过门；FEAT-006 r3 把"已有特征的组合形态"拧干——**全量叠加 +0.0094 未过门（共线稀释实证），y 盲剪枝 112／109 两候选改善点估计与 CI 但主种子仍未过门**。结论：已有信息的重组已到边际，缺的是信息本身。r4 裁定（叶安，2026-09-22）：

1. **新信息矿脉**：转向四类数据中尚未消费的数据面——轨迹表（连续驾驶／速度形态／空间结构／日节律）、同群相对化、画像基线偏差、夜间退化度，附带三项技术修正；
2. **瘦基座合并**：新增族**并入 FEAT-006 剪枝瘦基座**（不再全量叠加，吸收共线稀释教训），对冻结基线 RF@F0_v1 **只做一次**配对判定（防多重比较，判据不放松）；
3. **双收益**：新特征底座与事件级产物按任务二可消费 schema 一次成型（ADR-0005 §4：被消费即冻结）。

## 3. 技术方案

### 3.0 预登记定义（执行中不得擅改；确需变更随执行登记，判据不放松）

- **基座预登记**：候选基座＝FEAT-006 候选 B（lean，109 列清单见其 worklog／构建脚本产出的保留清单）。理由：列数最少、稀释最小、与新增族叠加后总列数可控。新列沿用 FEAT-006 §1 规则 7 收尾通则：**|Spearman ρ|>0.95 成对去后者（固定列序确定性）、近零方差剔除**，剔除清单登记受控台账。
- **窗口与红线**：特征窗 `[as_of−20d, as_of)`，lookback／horizon／as_of 显式配置、禁止硬编码（红线 6）；一切统计不触 `[as_of, as_of+H)`（合成测试断言）；原始高频序列不直接入模，入模的均为统计量与阈值事件计数（红线 4）。
- **禁外部数据**：空间特征仅自包含统计（坐标聚类／展布／路径重合度）；**不做地图匹配、不引入路网／POI 等外部库**。
- **同群相对化**：群键＝能源类型 ×（高速里程占比按车队中位二分）；特征＝群内 z-score 与群内百分位；**均值／方差等统计量按训练折内拟合**（红线 3），合成测试加折内拟合断言；群内不足 30 台回退全体统计并置回退标志。
- **夜间退化度**：深夜（23–5）事件率 ÷ 日间（9–17）事件率（六场景合并与分场景两版）；双侧最低样本门槛沿用 r2（500／300／100），零分母置缺失。
- **连续驾驶切段**：stage 0 先核轨迹 `运行时长` 字段语义——若为单行程累计时长则直接切段，否则以相邻点间隔 >180 min 切段并登记口径；产出最长连续驾驶、>4h 连续占比、深夜连续驾驶时长。
- **空间热点**：事件坐标 DBSCAN（Haversine，eps 200m，min_samples 2）；特征＝热点事件占比、热点数、同点位复发次数；路线重复度＝相邻日路径点集平均最近邻距离。
- **事件结构**：相邻事件间隔 ≤30 min 计连环（连环事件数、最大连环长）；共现＝同连环段内类型对计数（预登记显著组合入特征）；爆发性＝单日事件密度峰值 ÷ 窗内日均。
- **双速度源**：|EMS−GPS| 窗内均值／p95；事件发生时车速（交付表 `speed` 列）。
- **综合分合成**：方向统一后固定等权合成（"疲劳结构分"＝连续驾驶＋深夜连续＋疲劳报警夜间集中度；"夜间风险链分"＝夜间暴露＋深夜事件率＋夜间退化度）；**不做数据驱动调权**；组成列在特征字典登记。
- **近常数排除**：接口层按**方差阈值**排除（不再按缺失率），恒 0／常数列不得混入 model_input。
- **计数归一**：计数类一律 per_1000km／per_100h 双轨（沿用 F1），低暴露置缺失规则沿用；**入基座时按 FEAT-006 教训同场景只保留 per_1000km 版**（收尾通则统一处理）。
- **新增列上限 ≤40**（综合分优先、原始计数收敛），防 n=500 下特征膨胀。

### 3.1 stage 0：三项技术修正（先行）

1. 一切差分／滑窗／相邻行统计前按 `data_time` 稳定排序（分片内按车分组、组内时间排序；对 F0／F1 同款核查）；
2. 率类特征分母去逐字重复计数（并产出重复率列并行入模，lean 基座已有 dup_rate 则合并口径）；
3. 近常数列按方差排除（§3.0 口径）。

### 3.2 Tier 1：强信号精修＋同群＋画像偏差＋夜间退化

- **历史险情时间结构**：衰减加权计数（近 5 天权重 2）、复发间隔（末两次事件间隔）、爆发性指数、历史×趋势交互；
- **同群相对化**：仅对既有强特征做相对化（事件率、IMU 波动率、夜间占比的群内 z／百分位），不全量铺开；
- **画像基线偏差**：窗内里程／时长／夜间占比相对画像月均的偏差率（预期／实际对账）；
- **夜间退化度族**（§3.0 定义）。

### 3.3 Tier 2：轨迹一遍流式扫描（全部轨迹特征一次带出）

- **疲劳结构**：连续驾驶切段统计（§3.0）；
- **速度形态**：速度分位数（p50／p90／p99）、分时段超速占比、速度变异系数、高速巡航占比（持续 >80km/h 时长占比，道路类型**代理**，禁地图）；
- **空间结构**：热点复发、路线重复度、活动半径（坐标展布）、昼夜活动区偏移；
- **日节律**：每日里程 CV、断档天数、日均运行时长。

### 3.4 Tier 3：轻量顺手件

事件连环／共现／爆发（纯事件表）、|EMS−GPS| 一致性统计、事件时速。

### 3.5 实现与算力

- 新模块 `feature_engineering/src/accident_pipeline_f3/`（纯函数＋一遍扫描编排＋ interface 组装＋ cli），复用 r1／r2 对齐与事件产物，**不重跑 r1 三遍扫描**；
- 合成测试（真实数据前全绿必须）：窗口边界与标签窗排除、同群统计折内拟合、夜间比值门槛置缺失、切段边界、DBSCAN 已知簇恢复、连环计数、近常数排除、收尾剪枝确定性（同输入两次剔除清单一致）；
- 时间转换统一 ns 约定（r1 缺陷类教训）；轨迹扫描分块流式（参照 IMU 大表设计）。

## 4. 评估与消融（一次判定，防多重比较）

- 候选＝冻结 RF 规格 @（lean 109 基座＋新增族经收尾通则后）model_input，对基线 RF@F0_v1 车辆级配对 bootstrap（PREREG：2,000 次／95%／种子 42）**只判一次**；多种子旁证（42/7/2026）；
