## 1. 问题、证据身份与本轮假设

FEAT-009 在新协议中构建了 F1/F3 时间可见输入；F3 的五个外折均选中 EBM-A。F3 与 F1 的主比较同时改变了特征表和折内选型结果，无法单独估计“更多特征”与“更合适的学习器”各自的作用。固定 EBM-C 只以事后探索身份运行过；王健祺线的多视角融合为方法启发，但其成绩和 OOF 不作为本轮主对照。

当前 F3 含按事件类型展开的研究深夜特征。旧 FEAT-007 曾出现同类列占用预算、其他特征族未实际入模的问题；新版 F3 虽已从原始候选重建并折内筛列，仍未检验**保留主要深夜摘要、移开细分深夜列**后，不同模型是否更好利用其余特征。本轮唯一主假设是：**一个固定的“全量 F3 EBM-A＋精简深夜视角 EBM-C”预测融合，在同车同折代理 OOF 上改善全量 F3 EBM-A 的排序，同时不超过辅助指标容差。**

所有新增 OOF 都来自已经多次用于开发的同一批车辆。通过配对区间也只表示该代理协议下的探索证据，不能消除跨轮选型偏差，不能宣称官方未来窗口增益。方案接受、机器通过、实验效果通过和正式模型采纳分别记录。

## 3. 固定的实验矩阵与可归因比较

在任何新增真实 OOF 前，于受控 `preregistration.json` 写定列名、有序列表、哈希、版本、模型参数、主比较、预算和失败重启规则。两份特征视角从同一锁定 F3 表派生：

1. **全量 F3**：所有通过 FEAT-009 v2 禁止列校验的预测列，保持原顺序；`y/fold`、主键和版本字段只作元数据。
2. **深夜精简 F3**：仅从全量 F3 删除满足 `f3_night_*` 的按事件类型展开列；保留 `f3_night_deep_rate`、`f3_night_day_rate`、`f3_night_degradation`、`f3_night_exposure_share` 四个总览列，其他非 `f3_night_*` 列全部不变。这是**研究深夜 23:00–05:00 的列预算检验**，不把它改称官方夜间 21:00–06:00，不重算原始特征。若四列中有缺列，预登记不得锁定，先查来源。

两种学习器固定为已有配方，不在本轮搜参：EBM-A `interactions=0,max_bins=64,min_samples_leaf=10`；EBM-C `interactions=0,max_bins=32,min_samples_leaf=20`。其余参数、包版本、随机种子 42 与 FEAT-009 技术栈一致；缺失填补、编码、近零方差及相关剪枝均只在外折训练部分拟合。四个模型臂均使用同一冻结五折，每车仅有一条折外预测；没有按外折结果选择超参的步骤。

| 臂 | 特征 | 模型 | 作用与预先指定比较 |
| --- | --- | --- | --- |
| A | 全量 F3 | EBM-A | 本轮内部主对照；应复现 FEAT-009 F3 主跑的 OOF |
| B | 深夜精简 F3 | EBM-A | `B−A`：只改变特征视角 |
| C | 全量 F3 | EBM-C | `C−A`：只改变模型平滑；历史 EBM-C 结果仍属事后探索 |
| D | 深夜精简 F3 | EBM-C | `D−B` 与 `D−C`：观察模型效果是否依赖特征视角 |
| E | A、D 的预测 | 固定融合 | 唯一新增主候选；`E−A` 为主比较 |

E 不训练新模型。对 A 与 D 的 OOF 概率先裁剪到 `[1e-6,1−1e-6]`，各取 logit，**等权平均**后经 sigmoid 得到 E；权重、阈值和成员不能根据本轮外折结果改动。这样四个训练臂分别揭示特征影响、模型影响及二者交互，E 单独检验能否形成互补排序。B／C／D 的 AUC 与两两差异只作预指定的机制诊断；不能在看到分数后改称其中最高者为本轮主候选。若想改融合成员或权重，另开任务。

主指标为 `ΔAUC=AUC(E)−AUC(A)`，车辆级分层配对 bootstrap 2,000 次、种子 42、95% 百分位区间。辅助项为 `Recall@100(E)−Recall@100(A)≥−0.02` 与 `Brier(E)−Brier(A)≤0.005`；同时报告 AP、逐折类别数与 AUC、Top-100 变化。`ΔAUC>0` 且区间下界 `>0` 才写“本轮代理排序改善”；区间下界 `≥0.01` 才写“达到既有实际意义线”；辅助项有一项不合格则整体不建议采纳。再按同版 RF 锚点给出 E 的配对比较，但不得用 RF 取代本轮 A 对照。多个诊断臂和历史反复开发均在报告中明确标作探索；通过内部门不自动更改公共基线或胜过王健祺线。

### FEAT-011-S2 一次五折运行与独立复算（状态：`not_run`）

- **目的／依赖**：取得同车同折的 A–E 预测与归因，不在运行中改列、改配置或追分。依赖 S1 锁定。
- **具体操作**：新建 `outputs/feat-011/s2/<run-id>/`，从只读 Y1 表按外折训练 A–D，保存逐折拟合范围指纹、实际保留列、OOF、指标、配对区间、耗时、环境和输出哈希；E 从 A/D 同行 OOF 生成。首次完整有效 run 即为本轮判定；失败 run 保留错误与复跑原因。若 A 未在相同条件下复现 FEAT-009 F3 主跑，暂停主比较并查输入、预处理、种子和版本，不用新基线掩盖差异。
- **机器验收**：拟实现 `python3 -m feature_engineering.experiments.feat011.audit --run-dir <run-id>` 独立读取锁定清单和五臂 OOF，核验每车每臂恰一条、概率有限且在 `[0,1]`、外折训练与验证互斥、筛列／填补／编码／EBM 只见训练样本、输入与预登记哈希一致、E 概率可逐行复算、全部指标和区间可独立复算。至少用篡改一条 OOF、改一列特征、验证标签扰动三个合成坏例证明非零退出。A 对 FEAT-009 同输入同模型 OOF 若非字节相同，需逐车差异在浮点容差内且主要指标一致；容差与原因在 S1 锁定，超限即停。
- **人工可视化验收**：受控报告由同一 run 的底表生成：① 2×2 四臂指标及差分图；② E−A 配对区间和辅助指标表；③ A/E 逐车排名散点、Top-100 变化及逐折类别数／AUC；④ 按观测覆盖分层的人数与正类数。图标时间窗、版本、样本量、单位和一句结论；小群只作描述，不挑个别车辆讲“普遍规律”。叶安核对图、表和 OOF 同 run；评估责任人核对配对口径。
- **放行**：按 [验收规范](../ACCEPTANCE.md)分别报告实现／数据、实验效果、证据、人因／环境四维 `pass/partial/fail/not_run/blocked`；即使未提升也交接。实现者只能置任务 `review`，实际复核后才能记录 `accepted` 或负结果完成。

### FEAT-011-S3 跨线互补诊断与最终交接（状态：`not_run`）

- **目的／依赖**：判断叶安线预测是否可能补充团队模型，避免仅用两个各自的 AUC 做排行榜。依赖 S2 完成；王健祺线提供可核对版本的同协议逐车 OOF 或 model_score、标签／折分、列来源与时间可见性证据。其最终模型复现入口若仍与版本说明不符，先补对账，不强行融合。
- **具体操作**：只读联接 `gpsno/sample_id`、标签、折分和预测；分别给出 A/E 与对方共同正确、共同错误、各自独有的 Top-K 命中。跨线融合只允许产生**诊断性固定权重模拟**，不参与 S2 的预登记主判定、不升级任务一最终模型；后续正式融合需新任务及统一评估。
- **机器验收**：拟检查车辆集合、标签、折分、窗口、概率及来源指纹逐车一致；任何缺车、重复、训练可见性不明或用全样本拟合后回填 OOF 即非零退出。没有对方合格 OOF 时本步为 `blocked/not_run`，不妨碍 S2 的本线归因交接。
- **人工可视化验收**：受控双模型排名关系与错误交集图，标人数和正类数；明确“不作跨线采纳裁决”。交接写出互补是否有迹象、不能比较的原因、下一轮是否值得独立预登记。
- **放行**：叶安和王健祺双方核对受控来源后，只把结果交给团队终评；未取得共同证据则保持待对账，不编造胜负。

## 5. 预算、停止、回退与最终窗口边界

- 预算只含 **A–D 四个固定训练臂各一套五折 OOF＋E 的确定性融合**。不增加权重网格、模型池、夜间阈值、第二个特征裁剪组或新的特征提取。前置合成与单折成本试验不读取本轮真实 OOF 效果。
- 发现标签／折分／时间可见性冲突、S0 列集不守恒、A 无法复现、负向检查器放过坏例或预算无法承担时停止相应步骤，保留失败产物。主比较未过门也保存全部结果并收口；后续新假设另任务，不能按本轮结果反复改方案。
- 受控文件按 run ID 只增不覆盖；原 FEAT-009、FEAT-010 及王健祺线产物保持原身份。代码、配置和每一版本 OOF 有清单，回退只需停止消费 FEAT-011 的新版本。
- 本轮只验证 **20 天历史＋40 天代理标签**。最终 61 天输入属于 FEAT-010 A1 字段合同，不能接现有代理标签算 AUC；正式 8 月 1 日推理检查和团队最终提交仍是后续独立工作。
