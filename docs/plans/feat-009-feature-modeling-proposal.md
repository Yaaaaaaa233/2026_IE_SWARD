## 1. 问题、假设和证据边界

现有 F3R5_v1 主要按冻结 RF 判定；既有汇合诊断将新特征交给**在 F1 上选定成员的固定 V5**，未针对 F3 重新选择学习器与复杂度。前述实验只支持“这些直接组合未过门”，不能证明现有特征经模型适配后没有价值。历史消融和汇合诊断已看过标签，仅用于提出假设，不作为本任务的独立采纳证据。

- **H1（唯一主要效果假设）**：在 F3R5_v1 上，按预先锁定的小候选池于各外层训练折内选择学习器，可形成相对当前最强登记方案 V5 有正向增益的车辆级折外排序。
- **H2（次要机制假设）**：同一选择程序在 F3R5_v1 与 F1_v1 上的差异，可识别新增特征是否需要不同模型形态；两模型排错车辆可能互补。
- **局限**：五折 OOF 仍是开发期同一批车辆；既有多轮实验使最终赢家有选择偏差。即使 H1 过门，也只按 ADR-0004 登记为内部候选，不称独立测试成绩或通用性能上界。

| 对照 | 主比较：F3 选择程序 vs 当前最强登记 V5 的同车 OOF；同时报告 vs ADR-0004 原 RF 锚点。次比较：F3 与 F1 同选择程序。V5 在正式裁决前应核实输入／OOF 指纹和 `review` 验收状态；若 V6 已正式采纳，则补报对新的当前基线。 |

### FEAT-009-S1 四候选折内选择与一次主判定（状态：not_run；验收设计已冻结）

- **目的／依赖**：检验 H1，同时用同一选择程序回答 F1／F3 的模型适配差异。开始前必须完成 S0，补齐 FEAT-008、MODEL-005、EVAL-002 的具名复核记录，并确认四个预登记候选及运行依赖均可用；缺任何一项时保持 `blocked/not_run`，不能删候选后继续。
- **具体操作**：在固定外层五折内分别运行 F1 与 F3。每个外层训练部分再用 `StratifiedKFold(n_splits=3, shuffle=True, random_state=42)` 产生内层折；每个内层折独立拟合近零方差／Spearman 筛列、同群统计、缺失填补和类别编码，只把拟合变换应用于对应内层验证部分。F3 从已登记基座和原始新增特征表重建候选输入：丢弃预计算的同群派生列，按能源类别 × 高速占比重新构造群键；高速占比阈值、群均值／标准差／百分位和回退统计只从当前内层训练部分估计，再应用到验证部分。外层最终模型在完整外层训练部分重新拟合所有变换后预测外折；任何外折标签均不参与变换、筛列、模型选择或拟合。此处只重建已登记的表格变换，不重新扫描 IMU、轨迹或事件原始流。

  每个外层训练部分用内层三折平均 AUC 选择候选，完全并列时按候选登记顺序选择。候选固定为：EBM-A（`interactions=0`）和 EBM-B（`interactions=5`），两者均 `max_bins=64`、`min_samples_leaf=10`；LightGBM-A（`num_leaves=4`、`min_data_in_leaf=30`）和 LightGBM-B（`num_leaves=8`、`min_data_in_leaf=40`），两者均 `learning_rate=0.05`、`n_estimators=200`、`reg_lambda=1`、`feature_fraction=0.8`、无单调约束。运行 manifest 记录实际包版本、参数、数据与代码指纹、随机种子、运行编号和环境信息；如因 API 兼容需要采用等价参数别名，须在运行前记录映射，不得改变候选语义。

  唯一主效果判断为 F3 自适应选择流程相对当前登记 V5 的同车 OOF 配对 ΔAUC；原 RF、F1 流程、内层分数和逐折表现均为次级机制诊断。按 ADR-0004 进行车辆级配对 bootstrap（2,000 次、95% 百分位区间、seed 42）；点估计和区间下界都大于 0 才称“超过 V5”，区间下界至少 +0.01 才称“有实际意义增益”。同时单独报告 Recall@100 退化不超过 0.02、Brier 退化不超过 0.005 的容差。任一辅助项缺失时不得判通过。不得在看过主结果后换基线、指标、折分、候选或门槛；如 V5 复核状态尚未通过，不运行主判定。
- **机器验收**：拟实现 `python feature_engineering/experiments/task1_feature_modeling/run.py --config <local-config>` 与 `python feature_engineering/experiments/task1_feature_modeling/check.py --run-dir <controlled-run>`。检查每个样本恰有一个外折预测、外折训练／验证索引无交集且完整覆盖、主键唯一、概率有限且在 `[0,1]`、输入与 S0 指纹一致；`y`、`fold`、车辆标识、时间窗和版本元数据不得成为特征。负向合成测试覆盖重复／缺失输入、折分错误、标签或元数据入特征、训练验证重叠，以及外折验证标签扰动后候选选择、已拟合变换和预测必须不变；外折留出协变量扰动不得改变训练折拟合出的筛列、填补、编码、群统计或已选模型。所有变换器、候选与外层最终模型都须带训练行索引／指纹证明只见各自训练部分。固定配置重复运行的选型、OOF 与配对结果一致；中断运行保留失败状态，不能挑有利折。配对检查器输出 ΔAUC 点估计与区间、辅助容差和判定，并检查比较车辆一一配对。
- **人工可视化验收**：正式报告使用一组 run ID 下生成的主判定区间图、逐折选型诊断图／表、成本与效果图。图样 [FEAT-009-S1 合成验收预览](figures/feat-009-s1-acceptance-preview.png) 仅演示布局和读图标准，全部数值为编造示例，不是本任务结果。

  1. **同车 ΔAUC 区间图**：突出 F3−V5 主判定，原 RF 仅作次级锚点；标清 0（是否超过对照）与 +0.01（是否达到“有实际意义增益”）两条用途不同的参考线，并列样本量、正类数、bootstrap 次数和区间。Recall@100、Brier 容差另列同源指标表，明确“本线减对照”的方向及各自门槛。
  2. **外折选型表／图**：列五个外折的训练数、验证数、验证正类数、内层均值 AUC、选中候选与外折 AUC；醒目标为“诊断，不单独判定”。不能用某一折或候选的最好分数替代全体 OOF 主判定。
  3. **成本与效果图**：比较本次同代码、依赖和硬件下，在同一车辆集合与外层折分上运行的 F1 与 F3 流程，显示各自全流程 OOF AUC、wall time、峰值内存及实际模型拟合次数；特征输入版本分别标明，历史 V5 的 wall time 不放入比较。正式图表、底表和结果 JSON 必须来自同一 run ID，并显示数据窗口、数据／代码／配置版本、样本量和时间单位。

  人工验收通过标准：复核人不查代码也能指出唯一主判定；能区别区间是否跨 0 与区间下界是否达到 +0.01；能从指标表看懂两个辅助容差的方向和实值；不会把单折 AUC 当最终成绩；能确认成本图中 F1／F3 的运行条件一致。图表及标签、版本、样本量和单位与同 run ID 的机器结果一致。主图缺信息或图表结论与机器结果不符时退回修复。
- **放行**：本阶段机器验收全过且正式图表符合上述人工标准后，无论正负都登记主判定。过门只可提交人工 L2/L3 终评，不能自动采纳；未过门也不自动扩大调参，只有 S1 诊断显示明确研究价值时才提交 S2。
