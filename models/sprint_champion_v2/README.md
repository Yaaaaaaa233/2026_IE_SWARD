## 版本构成

四成员预测级加权融合（logit 尺度，权重 0.45 / 0.17 / 0.06 / 0.32），整链三种子（42/7/2026）logit 平均：

1. **g1 事件序列融合臂（0.45）**：EBM-A + EBM-C + RF(balanced) 三模 logit 平均；特征 = 事件表序列（语义率 per_1000km、险情时间结构、多窗口、类型转移/间隔/昼夜/连环/日节律），带防泄漏断言；
2. **g2 面板 EBM-C（0.17）**：vehicle_day 纵向面板（趋势/波动/断档/节律/覆盖/活跃）；
3. **g3 IMU EBM-C（0.06）**：IMU 方向无关模量（冲击/水平/旋转分位与超阈率、双速度源差异）；
4. **干净成员4 EBM-C（0.32）**：语义率双轨 + K4/K5 簇内相对 z + 能源 cohort z + 险情结构 + 轨迹精选 + FP 诊断交互块（夜间×事件率、观测×活跃等），事件全部特征窗过滤。

协议：label_v2_record_count_20260923 / split_v2_record_strat5_seed42（54 正类）；特征窗 [2026-06-01, 2026-06-21)。
