## 版本构成

四成员预测级加权融合（logit 尺度，权重 0.42 / 0.16 / 0.06 / 0.36），整链三种子（42/7/2026）logit 平均：

1. **g1 事件臂C（0.42）**：EBM-A + EBM-C + RF(balanced) 三模 logit 平均；事件表序列特征（带防泄漏断言）；
2. **面板+jn 块 EBM-C（0.16）**：vehicle_day 面板 + 轨迹×事件联合块（事件日 vs 非事件日对比、事件密度）；
3. **IMU+cs 块 EBM-C（0.06）**：IMU 方向无关模量 + 跨源一致性块（旗标/置信度/速度区间）；
4. **语义+cs+sp 块 EBM-B 交互5（0.36）**：语义率双轨 + 簇内相对 z + 险情结构 + 轨迹精选 + 一致性块 + 空间块，EBM 二阶交互=5（本轮主杠杆）。事件全部特征窗过滤（勘误教训）。
