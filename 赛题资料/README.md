## 赛题任务摘要

基于 G7 易流提供的 500 台货车 2026-06-01 ~ 07-30（60 天）驾驶行为数据，完成两项任务：

1. **任务一：事故预测算法** —— 利用过去 60 天驾驶行为数据，预测车辆未来 40 天内是否发生事故（含未遂事故）。输出二分类结果 + 概率值；按 **AUC** 排名。
2. **任务二：司机安全评价模型** —— 构建可解释、可运营、可动态更新的司机安全评分体系。评委按风险区分能力 35%、可解释性 25%、可运营性 20%、完整性 20% 加权打分。

**提交物**：预测结果 CSV、评分结果、算法/模型说明文档（PDF）、可复现代码（含运行说明）。

**注意事项**：禁止使用外部数据（违者成绩作废）；数据仅限本次比赛使用，不得泄露，赛后按要求删除；代码需可复现结果。

## 数据处理注意事项（摘自 IMU 参考资料）

- IMU 数据存在噪音/异常，个别时段不可用，需先做数据清洗
- IMU 设备放置姿态未必水平，需计算设备坐标系与车辆坐标系的映射关系
- 不同车型（电动、柴油、轻重卡）的风险信号特征可能有差异
- EMS 速度更精准实时但个别车辆有异常信号；GPS 速度有延迟但适配性好，可结合使用
- 风险触发不一定互斥（如急转弯和疑似侧翻可能同时发生）
