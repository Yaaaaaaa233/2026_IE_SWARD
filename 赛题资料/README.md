## 数据集概要

研究对象为 500 台货车 6-7 月的数据，共四类。**原始数据文件体积较大，不上传到本仓库**，请从官方渠道获取后放在本地 `data/` 目录（已被 `.gitignore` 忽略）。各数据集要点如下，完整字段定义见数据集说明 PDF：

| 附件 | 数据集 | 主要字段 |
| --- | --- | --- |
| `1.车辆画像数据.xlsx` | 车辆画像 | 设备号、能源类型、月均行驶里程/时长、月平均停留次数、高速里程占比、早晨/黄昏/夜间行驶时长与里程占比 |
| `2.风险事件明细.zip` | 风险事件（6-7 月） | 设备号、开始经纬度、事件类型编码与名称、速度、事件开始时间；共 25 种事件类型（超速、前碰撞预警、车道偏移、疲劳/分心类、盲区报警、事故/未遂事故等，编码 11401~60294） |
| `3.IMU数据（6-7 月）` | IMU 数据 | 设备号、设备串号、数据时间/日期、EMS 速度、GPS 速度、三轴加速度原始值、三轴角速度原始值。注意：需根据重力加速度方向和行驶方向做 IMU 坐标系与车辆坐标系的对齐 |
| `4.轨迹数据集（6-7 月）` | 轨迹数据 | 设备号、与上一轨迹点的距离、运行时长、数据产生时间、速度、航向角、GCJ02 坐标系经纬度 |

## 数据处理注意事项（摘自 IMU 参考资料）

- IMU 数据存在噪音/异常，个别时段不可用，需先做数据清洗
- IMU 设备放置姿态未必水平，需计算设备坐标系与车辆坐标系的映射关系
- 不同车型（电动、柴油、轻重卡）的风险信号特征可能有差异
- EMS 速度更精准实时但个别车辆有异常信号；GPS 速度有延迟但适配性好，可结合使用
- 风险触发不一定互斥（如急转弯和疑似侧翻可能同时发生）
