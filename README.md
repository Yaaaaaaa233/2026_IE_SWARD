# 2026_IE_SWARD

2026 清华 IE 亮剑（Agent 大赛）算法赛道《驾驶安全》参赛仓库。

## 赛题概要

2026 清华 Agent 大赛《驾驶安全》（G7 易流出题）：基于 500 台货车 2026-06-01 ~ 07-30 的四大类驾驶行为数据（风险事件、IMU、轨迹、车辆画像），完成两项任务：

1. **事故预测算法**：用过去 60 天驾驶行为预测未来 40 天是否发生事故（含未遂事故），按 AUC 评分。
2. **司机安全评价模型**：构建可解释、可运营、可动态更新的司机安全评分体系。

任务与评分细节见 [赛题资料/赛题说明.pdf](赛题资料/赛题说明.pdf)。
